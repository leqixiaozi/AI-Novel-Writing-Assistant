# 新设计 Release Gate

Release Gate 是发布证据账本，不是功能清单。每次评估追加记录，不覆盖历史。没有真实证据用 `unexecuted`；环境或二进制缺失用 `blocked`。

| 检查项 | 最低验收证据 |
|---|---|
| PG17 新装、升级与回滚 | 真实数据库日志、001—045 迁移结果、失败回滚记录 |
| Apache AGE / pgvector | PG17 二进制来源、哈希、加载、重建与恢复报告 |
| 三章完整创作链 | 开书至正式导出的全过程记录和版本引用 |
| 重启、并发与任务恢复 | 409、租约恢复、重试和死信演练报告 |
| 备份与恢复 | 整库＋附件备份、dry-run、实际恢复与一致性校验 |
| 三种导出格式 | Markdown/TXT/DOCX 打开、顺序与来源哈希比对 |
| 主题、终端与规模 | 全主题、桌面/移动、空态、大数据、性能和脱敏报告 |
| 旧系统并行隔离 | 新设计写路径审计，无 Prisma/SQLite 写入 |
| Windows 私有运行包 | 二进制、许可证、签名、安装和卸载保留数据 |

> 🏠 **白话比喻**：它像飞机起飞前的签字放行表。发动机装好不等于试车通过。对应到发布：代码存在不是验收结果，未跑过的动态场景必须保持未执行。

> 🧠 **速记方法**：**有证据才通过，缺环境就阻塞，没执行不猜测。**
