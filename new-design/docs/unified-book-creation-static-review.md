# 统一开书表单静态审查与验证

## 审查结论

- 非 AI 入口不直接创建书籍，AI 结果不再停在资料数量汇总；七种入口共用审阅集合与动态表单。
- 当前标题与字段值可编辑；已有条目的内容类型、来源及初始值由服务端锁定，新条目只能记录为手工来源。
- 草稿允许缺失必填值，但错误类型、未知字段与无效字典选择仍会拒绝；创建独立复用完整校验。
- 保存、选择方向和创建都核对修订号；生成任务在事务中抢占会话，不能同时启动或覆盖处理中表单。
- 最终安装只消费审阅集合，并保留原始值、当前值和来源；迁移会将既有 AI 初始资料带入审阅集合。
- 页面使用现有主题变量、无嵌套边框、响应式双栏和明确焦点；普通填写不展示英文稳定键、UUID 或 JSON。
