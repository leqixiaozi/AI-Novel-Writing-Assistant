# 章节创作工作台静态审查

## 审查范围

- 迁移连续性、外键、检查约束、不可变触发器和幂等回执。
- 人工保存、并发冲突、AI 请求、Outbox 投递、结果入库和采用准备调用链。
- 书内导航、兼容深链、桌面三栏、窄屏面板、未保存切章、错误提示和表单标签。
- 数据字典、运行包清单、README、开发 Wiki 与 F4 接口说明的一致性。

## 静态结论

- `chapter_documents/chapter_body_versions` 保持唯一正文正本，迁移 `039` 没有复制正文内容到其他业务表。
- 人工候选采用 `expectedRevision + idempotencyKey`，冲突返回 `409`，客户端刷新服务器候选时保留本地稿。
- AI 请求冻结计划、上下文、任务合同、提示词配方、模型路由和输入正文；任务创建继续触发既有 Outbox 桥接。
- AI 结果接收只写 `ai_candidate`；通用任务结果校验拒绝非候选、跨章节或已归档版本。
- “进入采用确认”只生成准备记录，不切换采用指针，也不触发事实或状态结算。
- 候选首版为整章比较，逐段合并与自由编排未在文案中声明可用。
- UI 使用语义颜色变量和低边框层级，可跟随现有主题；状态信息同时提供文字，不只依赖颜色。

## 执行的静态检查

- Server TypeScript：`npm exec tsc -- --noEmit -p tsconfig.server.json`
- Client TypeScript：`npm exec tsc -- --noEmit -p tsconfig.client.json`
- SQL 结构人工审查：表、外键、状态约束、触发器、幂等唯一键与迁移编号。
- 路由／文案／可访问性人工审查：标签、`role=alert/status`、键盘可操作按钮、窄屏面板和未保存对话框。
- Git 范围与空白错误：`git diff --check`，并排除仓库根目录 5 张用户截图。

## 未执行的动态验证

按本批开发策略，未运行单元测试、集成测试、构建、服务、浏览器、真实 PostgreSQL、迁移、AGE、pgvector、真实 AI、安装包、备份或恢复。这些项目必须在最终 Release Gate 验证，静态通过不能替代可发布结论。

重点动态债务：

1. 在真实 PostgreSQL 17 顺序执行 001—039，验证旧正文版本回填、不可变触发器和外键。
2. 两窗口并发保存、相同／不同幂等请求、迟到 AI 结果和来源换版拒绝。
3. Outbox 自动登记、worker 租约恢复、AI 候选入库后任务成功回执。
4. 四种主题下的桌面／窄屏交互、键盘操作、焦点顺序和长正文性能。
5. F4 消费采用准备时的正文切换、事实确认、状态结算与失败回滚。
