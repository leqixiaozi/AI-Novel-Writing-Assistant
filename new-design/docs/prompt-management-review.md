# 提示词分类树与编辑完整功能

## 范围与完成标准

用户从“新设计 → 创作资源 → 提示词管理”进入左右编辑工作区。左侧搜索分类／组件、收缩层级、原地新增子分类、同级上下移；右侧中文维护分类名称／上级，分类内新建组件，编辑名称、正文、说明、任务、职责与启停，查看正文预览。分类归档前提示引用数量及子级提升，正文不删除。

正文唯一正本仍为公共空间既有提示词组件卡及版本。051 只增组织主分类标记、成员版本标记、受控保存回执和七个可维护初始分类；旧组件不自动猜主分类，额外分组与标签引用保留。当前标签只展示既有引用，独立维度绑定／新增与后续配方选择器共用仍属后续完整功能，不冒充完成。

## 运行与恢复

作者组件不等于系统 PromptAsset。此完整功能不调用模型、不引入旧提示词网关；系统资产／结构化执行／独立入口下个功能接入。旧壳能展示当前页面不是全系统独立验收。

保存调用新设计受控入口，服务端仅接收五类可编辑值，稳定键与信任策略不让普通用户输入。新组件以请求标识生成稳定键；会话锁串行保存、同键同输入回执复读，换参拒绝。正文先保存，主分类另按卡片／分类修订及固定回执采用；分类失败明确正文已保存，重试同一请求不重复正文或成员。

> 白话比喻：图书换书架只调整目录，不复印正文；收银小票丢失先查付款记录。对应到系统：分组引用与正文版本分离，同一保存请求重复核对不再创建组件。

> 速记方法：分类管找，正文唯一；同键复读，换参拒绝。

分类排序同事务核实完整同级名单与修订号；分组移动及循环／跨空间约束复用已有树校验。主分类唯一索引与作用域触发器限制在提示词资源；旧主分类移动时结束旧主引用，额外成员不丢。修订冲突只读取服务器结果，保留当前编辑，显式选择核对后继续再保存。维护在新标签打开。
