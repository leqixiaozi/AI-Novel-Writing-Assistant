# F7 多维视图与质量闭环静态审查

## 覆盖范围

- 迁移 043 扩展书籍查看偏好与智能视图基础键范围，并为既有书补齐确定性默认配置；开书安装器会为旧模板补上缺失视图，不新增或复制小说业务正本。
- 多维读取直接查询章节、卡片关系、故事时间、正文锚点、正式事实、正式状态变化、质量报告和 AI 任务账本。
- AGE 与 pgvector 未进入任何编辑路径；它们不可用时，多维视图和 F8 稳定读取合同仍可工作。
- 质量问题沿用 025 的报告、证据、版本、人工决定、修订候选、采用引用和复检状态机；正文切版沿用 025/026 的失效传播。
- AI 修订入口进入 042 统一运行预览，返回结果仍需形成章节正文候选并通过 F3/F4/F5。

## 调用链核对

1. 路由 `/new-design/books/:id/views/:view` 挂载书籍外壳和单一“多维视图”导航项。
2. 客户端并行读取基础资料工作区与 `/api/new-design/books/:id/multiview-workspace`。
3. 服务端 `database/multiview` 模块只读 PostgreSQL 正本并计算连续稳定章节范围。
4. 卡片字段仍调用统一资料表单；人物关系、故事时间和伏笔仍先走影响预览。
5. 质量处理调用既有问题状态／版本接口；AI 修订链接携带书籍和问题来源进入统一运行预览。

## 本批验证边界

按批次要求，本阶段编码完成后只运行服务端和客户端 TypeScript `--noEmit`、SQL／状态机／调用链／差异和文档静态审查。未运行单元测试、集成测试、构建、服务、浏览器、真实 PostgreSQL、AI、worker、打包、备份或恢复。

进入 Release Gate 前仍需在真实 PostgreSQL 17 上顺序执行 001—043，覆盖既有书升级、全部主题、空数据、长列表、并发 409、质量失效、修订候选采用与复检闭环。
