## 可使用入口

开发工作台：[提示词组合](http://127.0.0.1:5194/new-design/resources/ai/prompt-composition)。路径位于创作资源；参考书籍必须明确选择，参数与组件先保存后预览。模型配置未启用时仍可保存并查看阻断预览，点击“打开模型设置”处理后重新生成预览。

> 速记方法：保存、预览、确认试运行；未知先核对。

## 已检查的失败闭环

精确版本与作用域、原子保存和严格幂等；空模型阻断预览；真实任务合同与显式上下文；冻结模型快照；单次领取／重复回执；终态与用量同事务；结果／字段冻结保护；未调用或未报告用量不虚构数字。临时 HTTP 验证错误阶段、中文问题字段、保留结果和固定可点击恢复地址。

试运行调用前重新编译受控任务，拒绝被冻结数据替换的消息与输出规格；作者组件不提升为系统指令。客户端未知试运行只读核对、不重提交；部分读取成功结果保留，保存成功后的目录失败保留成功凭证。模型和底座故障分别直接跳对应设置，其他返回原预览来源。

- Vite 包体 775.94 KB，gzip 215.73 KB，仍提示大于 500 KB；未隐瞒或通过调高阈值消除警告。
- 停止旧开发 API 时观察到 pg 关于同客户端并发查询的弃用提醒，尚未完成根因排查；新 API 正常启动。该提醒不作为已修复项，保留后续运行维护核查。
- 服务进程中断后旧领取只读核对，不自动再发模型；另一场试验需要明确新建预览。此阶段未增加自动重跑／跨进程模型结果重建能力。
- 本轮恢复覆盖组合与模型相关流程；全站其他创作流程按 [唯一队列](p1-p2-execution-queue.md) 逐项补齐。
