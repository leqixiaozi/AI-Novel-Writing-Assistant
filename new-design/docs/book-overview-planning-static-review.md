## 静态命令口径

```powershell
cd C:\AI-Novel-Writing-Assistant\new-design
pnpm exec tsc -p tsconfig.server.json --noEmit
pnpm exec tsc -p tsconfig.client.json --noEmit
```

迁移连续性通过读取 `runtime/runtime-package.spec.json` 的 `migrationRange` 并与 `migrations/` 文件列表比较；JSON 可被 PowerShell `ConvertFrom-Json` 正常解析。第一次从仓库根目录执行 TypeScript 检查时使用了错误配置路径，命令返回“配置不存在”；改到 `new-design/` 后两项均通过，该路径错误不属于代码失败。
