# 统一树资源静态审查

审查范围：迁移 046—047、字典树、多维标签树、内容类型绑定、动态表单、模板安装／升级、资源目录 UI 与相关 API。

## 结论

本阶段实现形成单一树规则合同：前端编辑器、运行时选择器、服务端请求校验和数据库引用校验使用同一组选择语义。左侧资源目录按范围折叠，右侧编辑当前树；节点顺序和父子关系写入 PostgreSQL，不依赖浏览器临时状态。

未发现阻断提交的类型错误或本阶段回归。未执行浏览器自动化；交互与视觉由用户在开发环境验收。

## 已检查边界

- 树循环：前端排除当前节点及其后代，数据库触发器再次拒绝自引用、跨树父节点和循环。
- 选择门禁：范围起点、相对层数、末级限制、父节点选择、最少／最多数量由服务端验证；卡片保存还会按当前数据库节点复核。
- 历史稳定：字典和标签节点追加不可变版本，卡片版本保存字典中文路径快照；停用不删除历史。
- 标签路径：祖先改名或移动会为后代追加版本并刷新当前完整路径。
- 模板复制：字典、标签和规则中的源 ID 均映射为书内 ID；种子资料中的树节点值同步映射。
- 模板升级：只自动添加新树、新节点和新绑定，既有节点或规则变化进入冲突，不覆盖本书修改。
- 查询：选择父标签时可匹配后代成员，标签成员关系仍只保存一次。
- 跨机器：迁移 SQL 与结构文档进入 Git；业务数据继续通过 PostgreSQL 逻辑备份恢复。
