# 客户术语与新设计导航静态审查

日期：2026-09-16

## 审查范围

- 桌面侧栏与移动端更多入口
- 新设计首页、书籍列表、创作资源、研究与分析、高级设置
- 书籍任务导航、资料编辑、事件规划和基础视图
- 旧深链兼容、主题复用边界与跨机器同步说明

## 静态结论

- `/new-design` 继续是默认创作首页。
- `/new-design/books/:bookId/forms` 继续是开书后的主入口。
- 原有 `/cards`、`/fields` 和 `/views/*` 地址没有改名或删除。
- 顶层菜单只有创作首页、我的书籍、创作资源、研究与分析；高级设置默认收起。
- 当前地址位于 `/new-design/structure/*` 时，桌面和移动高级设置都会自动展开并显示活动项。
- 高级设置开关使用原生按钮，带 `aria-expanded` 和 `aria-controls`，可通过键盘操作。
- 书籍导航按创作概览、人物、世界设定、剧情与事件、章节、线索与伏笔、本书资料、本书设置组织。
- 普通创作页面未发现“元卡片类型、卡片组表单、模板组、卡片库、卡片挂载、关系边、card_type_id、JSON Schema”等暴露文案。
- 公共创作资源与单书资料使用不同标题、说明和入口；人物、世界、剧情等内容不会被描述为公共资源。
- 新设计仍复用主应用语义主题变量，没有增加独立颜色主题或固定色值。

## 已执行的静态检查

- `pnpm --filter @ai-novel/new-design typecheck:client`
- `pnpm --filter @ai-novel/client exec tsc --noEmit`
- `git diff --check`
- 菜单标签、书籍任务标签、禁用术语和 ARIA 属性的文本扫描

以上命令不启动服务、不连接数据库、不执行构建，也不运行单元、集成或浏览器测试。
