# F6 研究、提示词与运行编排静态审查

## 审查结论

- 迁移 042 只新增表、列、约束、索引、触发器和确定性基础数据，不删除用户数据。
- 研究结果进入书籍必须经过本书可编辑采用批次；旧拆书接口直接新建或合并书内资料会失败关闭。
- 运行预览冻结合同、配方、上下文、路由、输入、预算、安全检查点和阻断项；相同幂等键绑定请求哈希，不能被另一份请求复用。
- 提交前重新核对章节检查点、上下文状态、路由哈希和旧章换稿阻断项；变化返回 409。
- AI task 继续复用 030 的 Outbox 触发器，没有新增旁路队列；密钥 locator 和真实密钥不进入公开合同。
- 章节写作结果继续进入正文候选，变化提取结果继续进入待确认提案，不直接修改正文或正式事实。
- 私有运行包 manifest、迁移计数、诊断文案和同步文档统一到 001—042。

## 状态与事务检查

- 采用批次只有 `draft → adopted`，条目采用与正式卡片创建在同一事务内，任一规格校验失败会整体回滚。
- 运行预览只允许 `ready → submitted/stale` 或 `blocked → stale`；提示词分区与提交回执禁止更新和删除。
- 采用、预览与提交都保存幂等键。预览类请求额外保存请求哈希，重复键携带不同输入时返回冲突。
- 同一研究候选可以被不同书籍采用；采用过程不修改共享候选状态，因此不会阻断其他书籍。
- 来源更新通过当前版本指针比较产生提示，冻结批次和历史运行不会被覆盖。
