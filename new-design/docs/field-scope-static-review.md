# U3“添加信息”与字段作用域静态审查

审查日期：2026-09-16

## 已完成

- 作用域：新增前明确选择本书同类或当前资料；关联局部入口禁用并说明由后续开放，未实现 U4 选择器。
- 来源：核心、模板、本书新增、仅此处补充均有稳定内部枚举和客户语言标签；查询返回来源版本。
- 版本：字段、选项、采用记录和局部值历史只追加；改名不改 key，选项名称与 ID 分离。
- 事务：本书新增锁定书籍／类型当前修订，同时发布新的类型与适用表单版本；冲突返回 `409`。
- 数据隔离：所有查询和写入校验书籍空间、内容类型和资料归属；书内操作不写公共空间或其他书。
- 值边界：类型值和当前资料局部值在持久层分开，统一表单只在渲染时合并；保存仍追加一个不可变 `CardVersion`。
- 影响预览：显示现有同类资料数量；已有资料的新必填项必须提供安全默认值，未实现的逐条补齐不提供可点击假入口。
- 归档：核心字段禁止归档，必填模板字段禁止隐藏；其他字段发布隐藏版本或归档局部定义，不物理删除历史。
- 可访问性：范围选择使用单选控件，字段都有可见标签，动态预览／错误使用 `aria-live`，对话框有可读名称。
- 静态检查：服务端与客户端 TypeScript `--noEmit` 均通过；`git diff --check` 见提交前审查。

## 边界

本批未实现关联选择、挂载局部值编辑、标签／分组／智能视图和三章生产闭环；AI 只显示可建议能力，不连接真实生成。

遵照开发优先策略，本批没有运行单元测试、集成测试、构建、服务、浏览器、截图、真实 PostgreSQL、迁移执行、安装包、备份或恢复。

## Release Gate

1. 在真实 PostgreSQL 顺序执行 001—034，验证触发器、不可变约束、外键和旧书字段登记。
2. 四套主题和明暗模式人工检查桌面／窄屏、键盘焦点、长字段名、50 个选项和错误状态。
3. 双窗口制造本书类型、当前资料和字段修订冲突，确认 `409` 与幂等重试。
4. 验证必填＋已有 0／1／大量资料、安全默认值和选项默认值转换。
5. 验证字段／选项改名、隐藏、旧 `CardVersion` 回看和备份跨机器恢复。
6. U4 接入时只复用 `card_mount` 合同，不把关联局部值混入来源卡片。
