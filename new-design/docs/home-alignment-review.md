## 最新执行边界与真实差异

用户随后明确“页面按旧版来，兼容我们新的底层”。呈现按旧五区及主次布局适配，不能把新版数据差异解释为任意裁剪功能的许可。

短篇独立流程、新版 simple/professional 分流帮助、旧全书导演百分比和整体资源评分均没有对应契约。现有开书页可选择自动/逐步/人工，但没有首页直达不同模式的参数，因此长篇准备和手动创建均先进入同一开书表单；不能宣称两个链接已分别预选模式。模型提示返回既有模型设置页，不复制旧快捷配置弹窗。首页恢复操作返回带原 run/session 的来源页，不在首页直接执行。这些差异须明确报告，不能以 15 项测试通过代替功能等价或用户认可。

用户拒绝新增安全启动模式/重启建议，5301 保持原进程；上线生效属于未完成项。首页源码可能被前端热加载，但这不代表新后端接口已存在，不应直接当作完整可用首页交付。

编译副作用记录：全服务端编译虽被范围外类型错误阻挡，但 TypeScript 默认仍输出 dist。旧 API 的 ts-node-dev 监视器在 15:14:52/15:14:56 检测到 dist/common/contracts.js 与 dist/server/http/router.js 变化而自动重启，旧 API PID 变为 828280；日志确认仍采用 comparison startup，跳过迁移、初始化、清理和后台恢复。未主动启停服务，但不能表述为所有进程都从未重启。后续类型检查均使用 noEmit；5301 PID632116 和入口5273 PID766472未变。
