# 研究采用与统一 AI 运行编排

本文说明 `042_research_prompt_runtime_orchestration.sql` 的数据边界。迁移、内置合同与本文一同进入 Git；开发者在另一台机器拉取代码并执行迁移后，可以得到相同结构和系统内置数据。作者真实填写的资料、采用决定与运行记录仍需通过 PostgreSQL 逻辑备份同步。

## 研究资料进入书籍

研究扫描、市场分析和作品拆解保持独立。它们先产生不可变研究版本、证据和 `research_candidates`，不能直接修改书内正式资料。

进入书籍时创建：

- `book_research_adoption_batches`：锁定目标书籍、来源精确版本、候选集合哈希和当时的来源说明。
- `book_research_adoption_items`：复制候选标题与字段为本书可编辑草案，并分别记录 `pending / adopt / reject`。
- `book_research_adoption_events`：保存预览、编辑、决定和采用的幂等流水。

同一个研究版本可以被多本书分别引用。来源后续发布新版本时，旧采用批次只显示更新提示，不覆盖冻结内容。采用动作在单个事务内校验当前内容规格，为所选条目创建正式卡片、卡片版本、字段来源和本书研究引用；未选择条目仍留在研究资产中。

> 🏠 **白话比喻**：研究候选像出版社收到的素材剪报，采用批次像某本书专属的选稿篮。编辑可以在篮子里改标题、划掉不用的内容，最终盖章的条目才进入书稿档案；剪报更新不会偷偷替换篮子里的旧稿。对应到数据库：共享候选保持独立，本书批次负责编辑和决定，正式卡片只由采用事务创建。

> 🧠 **速记方法**：**研究先候选，入书先预览；逐条可修改，盖章才正式。**

## 模型路由层级

模型路由按以下顺序叠加，后层只覆盖自己明确提供的字段：

1. 系统默认 `system_default`
2. 任务组 `task_group`
3. 具体任务 `task`
4. 兼容节点规则 `node`
5. 本书 `book`
6. 本次运行 `one_time`

`task_key` 让同一任务组内的“章节写作”和“变化提取”可以选择不同模型。`one_time` 只影响一次预览。公开合同与快照仅返回 `hasCredential`，不返回密钥定位或真实密钥。备用模型只接受超时、限流、认证、供应商不可用、传输和上下文超限等技术故障类别；内容质量不触发自动换模重试。

> 🏠 **白话比喻**：路由像公司报销标准：先有全公司规则，再有部门、具体岗位、项目和本次出差的补充说明。后面的说明可以细化前面的规则，但不能把银行卡密码印在报销单上。对应到系统：层级路由逐层合并，凭据只保留安全引用。

> 🧠 **速记方法**：**系统打底，组和任务细分，书与本次收口；故障才回退，内容不换模。**

## 统一运行预览

`ai_run_previews` 是 AI 任务进入队列前的不可变确认单，冻结：

- 任务合同与提示词配方版本；
- 输入快照与输入哈希；
- 上下文装配预览、正式 manifest 和确切来源；
- 模型路由快照、来源层级与技术回退；
- Token 预算；
- 章节正文修订、采用正文等安全检查点；
- 旧章换稿等待复核或执行中的阻断项。

`ai_run_prompt_sections` 以指令、正式资料、参考资料和输出合同四类分区列出精确来源。`ai_run_submissions` 把一次确认提交绑定到唯一 `ai_task`。任务创建后，既有 AI task 触发器继续写入 Outbox，042 不建立第二套队列。

提交时重新核对预览修订、上下文状态、路由快照哈希、安全检查点和换稿阻断项；任一来源变化都返回 409，调用方必须重新生成预览。预览提交后只读，不能修改冻结字段。

> 🏠 **白话比喻**：运行预览像手术前核对单：病人、方案、器械、药量和主刀医生都要逐项签字。签字后任何一项变化都必须重开核对单，不能在手术途中改旧单。对应到系统：预览冻结全部执行来源，提交只接受同一修订和同一安全检查点。

> 🧠 **速记方法**：**合同、输入、上下文、路由、预算、检查点六项冻结；有变化就 409 重开。**

## 已接入与未接入入口

已接入统一运行预览：

- 高级设置中的手动统一运行确认；
- 章节创作 AI 操作；
- 章节采用后的变化提取。

保持独立：

- 开书会话与表单辅助仍使用自身候选协议；
- 市场分析与作品拆解的 AI 运行仍属于研究域，只有研究结果进入某本书时使用可编辑采用预览。

这份范围通过稳定读取合同返回给前端，不能把未接入入口展示为已接入。

## 跨机器同步

- Git 同步：`migrations/042_research_prompt_runtime_orchestration.sql`、迁移注册、内置提示词配方、任务合同、默认路由和本文。
- PostgreSQL 备份同步：作者书籍、研究运行、采用批次、运行预览、任务与 Outbox 数据。
- 受管附件同步：研究原文、附件及其 manifest；只复制数据库目录或只复制附件目录都不是完整恢复。
