# 新版页面布局与样式约定

## 范围与依据

适用于 `new-design/src/client/` 的新页面及现有页面调整。页面骨架与通用样式以 `new-design.css` 为准，页面壳内还需核对 `legacySurface.css` 的覆盖规则，主题色和明暗模式以 `standalone/theme.css` 为准；书内创作工作台还需遵守其局部样式。根目录 `AGENTS.md` 的低边框规则仍是默认要求：普通内容靠标题、间距和浅底色分组，边框用于表单控件、选中状态、列表分隔和确实需要区分的交互区域。用户明确指定的页面调整优先。

下表是 2026-09-23 对 `src/client/` 下 `.tsx` 文件用 `rg -l -F` 统计的**包含该类名的文件数**。一个文件只计一次；数字说明现有复用范围，不代表渲染次数，也不要求所有页面套用同一种布局。

| 现有样式 | 文件数 | 用途与生成时的选择 |
| --- | ---: | --- |
| `nd-shell` | 40 | 标准页面容器，约束宽度、文字、主题变量和横向溢出；独立页面先沿用所属 Shell。 |
| `nd-page-header` | 14 | 面包屑／页名／说明／主要入口的首屏层级；不要用普通卡片代替页头。 |
| `nd-subnav` | 6 | 同一业务区的子导航；跨路由用链接，页面内切换用按钮，二者共用间距与选中样式。 |
| `nd-row-actions` | 51 | 同一任务的操作按钮组合；窄屏允许换行，主要动作另用 `nd-button-primary`。 |
| `nd-control` | 65 | 标签与输入框的组合；保持可见字段名、主题控件样式及可点触尺寸。 |
| `nd-button` | 164 | 标准操作入口；链接和按钮按真实导航／操作语义选元素，不依赖浏览器原生按钮外观。 |
| `nd-message` | 69 | 成功、失败和需核对的状态提示；错误说明下一步，不能只给颜色。 |
| `nd-empty-state` | 11 | 无记录或未选择对象时的引导；说明当前为空的原因和可采取的动作。 |

## 常用布局

1. **标准页面**：所属 Shell → `nd-page-header` → 必要时的 `nd-subnav` → 正文。顶部导航负责业务区切换，局部导航只切换本页内容。标题工坊使用资源 Shell 和两层不同范围的导航。
2. **表单与结果**：`nd-control` 标注输入，相关操作进入 `nd-row-actions`；生成结果、来源和待核对回执各自有清晰标题。只有表单边界确有意义时才用 `fieldset`，避免内外连续套边框。
3. **列表与详情**：宽屏可左右分栏，窄屏改为上下排列；选中行同时有背景和标识线。模型路线选择与运行记录已采用明确的外框／分隔线，新增同类页面先参考它们，普通内容段落仍保持低边框。
4. **状态区域**：加载、空态、失败、待确认都留在原操作位置；保留已有内容时明确说明，不用空白区域暗示成功。

## 新页面生成与修改规则

- 所有可操作按钮和操作型链接使用 `nd-button`；未指定变体时即为次要按钮，唯一主要提交动作用 `nd-button-primary`，危险动作用 `nd-button-danger`。同一区域的按钮高度、内距、禁用态、悬停态和键盘焦点要一致，不依赖浏览器原生灰色按钮。
- 文本框、下拉框、长文本框应有可见标签，并沿用 `nd-control` 或同等的主题变量：`--nd-canvas` 背景、`--nd-ink` 文字、`hsl(var(--input))` 边框、`hsl(var(--ring))` 焦点。占位文字只作示例，不代替标签；禁用态仍可读，长文本框允许垂直调整大小。
- 会话／聊天类工作区也按上述表单与按钮规则处理；诊断输入与上下文绑定控件必须使用同一尺寸和明暗主题，快捷提问是按钮而不是普通文本。选中会话同时显示背景和边缘标识。
- 先查所属 Shell、`new-design.css`、`legacySurface.css` 的适用覆盖及一个同类页面，复用已有类名和 `--nd-*` 主题变量；只为本页特有结构写局部 CSS，不重新定义一套按钮、标签页或配色。
- `nd-subnav` 的路由项用 `<a>`，局部切换用 `type="button"` 并同步 `aria-pressed`；当前项必须有可见选中态。使用链接时保留真实深链，不把导航做成无地址点击。
- 容器和网格用 `min-width: 0` 防止长中文标题、凭证和表单撑破页面；桌面至少核对常见 1280px 宽度，窄屏核对折行、栏位顺序和横向滚动。
- 保留 `:focus-visible`、禁用态和错误态；只有需要表示边界的区域加边框，同一区域不要叠加多层边框和阴影。
- 调整共享样式后检查使用该类名的其他页面，避免只修目标截图却让链接与按钮、明暗主题或窄屏状态分叉。
