# 新设计阶段交付记录

仅记录受控新设计范围的交付；全仓库发布记录不在本轮修改范围内。

### 2026-09-16

#### 新增

- 空白资料支持“AI 填写必填项”“AI 补充剩余内容”“AI 全部准备”，可选择本书参考资料；名称建议与内容一起逐项采用，正式保存才检查必填。
- 资料表单与多维编辑器提供 AI 填空、补充、检查矛盾、三个方案、按要求调整和选项／标签推荐。建议逐项采用到草稿，检查后随资料一起保存。
- 采用 AI 建议时保留未勾选的人工修改，来源变化时提示复核，不自动覆盖正式资料。

#### 优化

- 字典与标签节点集中到左侧可收缩树，右侧编辑当前项目，支持搜索、新增与同级上下移。
- 研究提案使用中文字段表单填写，保留待复核内容；创作概览用任务名称展示最近运行。
- 上下文规则按中文名称选择资料、版本、作用对象和条件分组，编辑时保留额外入口及已有嵌套条件。

#### 修复

- 修复事件保存后关联工作区因 SQL 保留字别名而不可用的问题，保留原有关系规格及锁定语义。
- 修复开发数据库连接环境不同导致开书和资料规格保存失败的问题。
- 普通页面服务失败时提供重试与维护入口指引，避免铺满内部构建错误。
- 研究提案采用前核实允许选项范围，保留采用时的历史名称，重复请求不重复写入资料。

完整定向验证与未执行项见 [AI 表单运行证据](business-form-ai-assist-review.md)。剩余 P1／P2 见 [执行队列](p1-p2-execution-queue.md)。
