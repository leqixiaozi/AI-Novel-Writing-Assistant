# 创作首页的数据与操作边界

## 目标与范围

首页帮助作者回到当前需要关注的作品，查看下一步、创作进度和资料积累。首页只消费新版业务事实，不导入旧版首页组件、业务服务或 SQLite 数据。全局菜单、布局外壳和版本入口不属于首页模块。

## 只读查询

`/api/new-design/home/snapshot` 在单个 `REPEATABLE READ READ ONLY` 事务中读取全部未归档作品，独立账本先按书籍聚合，避免多表连接造成重复统计。任务数量用于判断作品状态，每个作品在同一统计项中最多计一次；开书草稿单独显示，不冒充正式作品。不能使用截断目录或最近若干本计算“全部作品”。

查询只接受已初始化数据库池。冷启动时返回不可用，不因作者打开首页而启动数据库、执行迁移或恢复任务。首页路由在研究恢复中间件之前挂载。读取失败保留已有画面并显示过期提示，不能用零替代读取失败。

模型配置读取检查现有任务路由及凭据可用性，不请求模型、不保存设置。配置可用不表示网络探测成功。模型状态与作品状态分开处理，一方失败不抹掉另一方的已保存结果。

## 事实语义

- 候选保存、正文采用、当前正文稳定结算是三种不同事实。生产导演范围候选全部保存不表示整本书完成。
- 六阶段展示对应的正式事实证据，不能依据开书候选游标或阶段数量伪造全书完成百分比。
- 正文计数只包含当前明确采用且非空的正文；稳定计数要求检查点对应同一当前采用版本。
- 结构条件通过的章节只表示可进入正文准备，实际执行仍需在来源页校验上下文、模型、前章稳定性和本次范围。
- 已填必填项除以现存资料必填项总数是字段填写统计，不是旧版的整体资源准备评分；无分母时不能显示满分。

## 操作与模块归属

首页依据已有结构化状态选择展示顺序，不执行创作意图识别。恢复、采用、重试等命令留在原来源页；首页主操作只有导航。原导演链接保留 run，原开书草稿链接保留 session，不新建平行流程。运行记录保持只读。

契约和显示规则位于 `src/common/home`，查询位于 `src/server/database/home`，HTTP 映射位于 `src/server/http/home`，首页组件和局部样式位于 `src/client/home`。查询计数细节见数据库模块 README。
