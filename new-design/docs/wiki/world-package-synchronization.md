# 公共世界固定来源与独立书内资料

## 决定

公共世界供作品复用，书内档案、已发生事实和人物认知各自有正本。共用可修改世界对象会把一本书的修改传播到其他书；移动安装基线会把作者改动误判为公共更新。公共包因此固定实际卡片、类型、表单、关系和字典节点版本，安装生成独立正常书内资料并记录完整来源映射。

包表只持久发布、安装和原请求元数据，档案正本仍在cards／card_versions。类型能力等未独立版本化的元数据与实际类型版本一起冻结，不用未来当前规格替换历史包。六分区沿用概要、规则、阵营、势力、地点、关系网络，由作者明确归属，禁止按名称猜测。

## 当前规则

读取、预览与原请求核对只读，不写待同步摘要、不建任务或请求模型。完整来源字段须明确映射，缺键与null、空值、0、false分别处理，重复、未知或缺映射拒绝。本书实际类型、明确表单和字典经正常校验，公共节点不能冒充书内节点。重名资料保持不变。

各正常卡片使用独立预分配保存原键，全包资料、正常作者回执与安装映射在一个物理事务内提交。COMMIT确认丢失、原查询失败及回滚不明均保持unknown；只读核对不是重新执行授权。同原键不同完整输入拒绝。归档和能力停用后历史仍可核对。

被包引用的卡片、类型、表单和字典历史有数据库保护，正常编辑新增版本。包／安装和映射不可修改或删除；延后约束要求完整引用集合。084不加入普通启动且默认关闭能力，缺保护触发器同样不可写。

## 备份恢复与生效边界

只在新空隔离库验证084。完整pg_dump后核对备份存在、尺寸、PGDMP头和SHA256，再恢复到另一个经验证为空的新库；比对包、安装、实际资料及事实／状态／正文等完整行，核对触发器恢复。保留全部成功／失败库和备份，不借此修改作者库或重启作者服务。

作者库安装／启用、在线加载、用户验收分别记录。回退只关闭operational，历史保留，不删表或回写共享资料。

## 阶段边界

固定版本与无关系包独立安装属于已验证的历史基础切片。后续完整关系转移、本书世界首次公开候选／明确发布、字段／新增对象／关系三方pull、push公共候选／明确发布、双方基线与同步历史及来源页面已接入代码，仍待统一功能验证。纯比较、基础历史检查与编译不能代替实际保存验证，D及在线状态保持未完成。
