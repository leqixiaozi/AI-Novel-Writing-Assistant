# 人物对话模拟边界

真实作者入口是本书“人物对话模拟”，不是运行记录的变更按钮。入口从稳定章选择当时资料；单次受控模型执行只产生非事实台词／动作候选。原正文、状态、认知、关系和规划正本仍由各原模块负责。

像先排练再出版：彩排发言不是剧情事实，把动作圈出来也只是编辑建议。对应到代码，回合保存在原 task/attempt/usage 与专属非事实沙盘；作者另点“把勾选动作加入规划草稿”才在同事务调用原规划 writer，仍需在故事规划明确采用。速记：**定章验源、模拟审阅、选入草稿、正式另采**。

截至章来源不足不借当前/未来档案补齐。历史关系缺少不可变规格证明时会真实阻断相关范围；模型设置存在只是配置，不是实测成功。原回复首次 DB 保存失败没有额外 durable spool 保证，不承诺重启后保留内存回复，未知仍不重调。

纯数据库未知保存可以显式按同键完整 payload 核对并完成原操作；模型未知只核对原回执或结束已超期未知领取。GET 阴性、坏浏览器存储和缺身份旧凭证不解锁。初始领取回滚证明本身丢失且无可读回合/租约时，保留真实阻塞而非伪造终态。

已编码及静态审阅；未执行安装、build、typecheck、test、migration、服务/HTTP 或模型调用。单元与专属空隔离 PG 来源拒绝用例已写，实际历史成功范围、跨域并发锁、模型单次执行、原规划安装和浏览器多主题恢复仍待集中验收。

## 公共档案试聊与图片

公共档案试用的来源是原公共角色确切版本及其原规格／局部字段版本，不是本书截至章沙盘。入口 `/new-design/resources/characters/workshop` 使用独立受控资产 `new_design.character.public_dialogue@v1`；只复用已发布人物对话模型路线，不借用书内对话输入、私有认知、未来正文或通用稿件诊断。每轮须核对同一角色／版本／哈希的完整此前成功回复，最多31轮；台词、档案表现及缺失信息没有正式写入权。

公共任务没有bookId。手动097扩展原上下文清单的明确公共角色范围并保留原Task／Step／Attempt／Usage链，不造全局书。公共清单和尝试仍注册原依赖资源并引用确切来源；书级失效边及知识状态保持原书级合同，不给公共请求写入NULL书或虚构书级状态。扩展保留已安装约束分支、解析／依赖函数OID及触发器连接，默认关闭且不注册普通启动迁移。

公共试聊和公共图片的有效回复使用原安全文件机制先持久完整范围／版本／请求／尝试／输入哈希凭证，再登记数据库结果；它仅保留接收证据，不是第二份人物或图片正本。首次数据库保存中断可只读核对并续存原回复，不能重调模型；书内对话原有无专属durable spool的限制仍单独保持，不能把公共恢复保证泛化到书内沙盘。

公共图片复用专属图片协议、确切连接和原受控内容对象；主图／归档为追加原结果引用，核对最新事件并保留文件和历史，不自动回写角色、导入书籍或替补主图。前后端编译通过，功能用例尚未统一执行；097未安装作者库，未重新加载作者服务或调用真实模型。
