# 人物对话模拟边界

真实作者入口是本书“人物对话模拟”，不是运行记录的变更按钮。入口从稳定章选择当时资料；单次受控模型执行只产生非事实台词／动作候选。原正文、状态、认知、关系和规划正本仍由各原模块负责。

像先排练再出版：彩排发言不是剧情事实，把动作圈出来也只是编辑建议。对应到代码，回合保存在原 task/attempt/usage 与专属非事实沙盘；作者另点“把勾选动作加入规划草稿”才在同事务调用原规划 writer，仍需在故事规划明确采用。速记：**定章验源、模拟审阅、选入草稿、正式另采**。

截至章来源不足不借当前/未来档案补齐。历史关系缺少不可变规格证明时会真实阻断相关范围；模型设置存在只是配置，不是实测成功。原回复首次 DB 保存失败没有额外 durable spool 保证，不承诺重启后保留内存回复，未知仍不重调。

纯数据库未知保存可以显式按同键完整 payload 核对并完成原操作；模型未知只核对原回执或结束已超期未知领取。GET 阴性、坏浏览器存储和缺身份旧凭证不解锁。初始领取回滚证明本身丢失且无可读回合/租约时，保留真实阻塞而非伪造终态。

已编码及静态审阅；未执行安装、build、typecheck、test、migration、服务/HTTP 或模型调用。单元与专属空隔离 PG 来源拒绝用例已写，实际历史成功范围、跨域并发锁、模型单次执行、原规划安装和浏览器多主题恢复仍待集中验收。
