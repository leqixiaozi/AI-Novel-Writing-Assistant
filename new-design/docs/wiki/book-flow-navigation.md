# 本书流程目录

书内目录服务于新手的创作顺序：创作概览、创作方向、故事设定、故事规划、查看与分析、全书导演、完本与导出。只为故事规划保留“规划与正文”及三个实际子页面；资料类型和辅助工具不作为主目录分类。

## 呈现与职责

- `BookShell` 保持全局导航之外的本书目录和主工作区，书名、返回书架与本书设置在目录顶部。
- `bookNavigation/catalog.ts` 使用既有任务路径构建目录；`BookFlowNavigation` 专门呈现流程步骤，不修改资源库的通用树样式。
- 主项15px/44px、子项14px/42px；缩进、选中底色和左侧竖线表达当前位置。只有有子页面的分组显示展开图标，标题与箭头由同一按钮操作。
- 当前具体页面决定祖先展开和唯一选中。收起目录只隐藏目录内容并释放宽度，不卸载主工作区，也不修改URL、查询条件或业务数据。

## 辅助功能归属

人物模拟、视觉资产和知识参考从故事设定标题操作区进入，并返回故事设定；专业图形从查看与分析进入，并返回查看与分析。这些页面沿用独立的真实路由，在主目录选中其所属步骤。

目录和辅助入口使用真实链接，继续由原页面的保存保护与草稿保留机制处理离开操作。分组按钮不触发导航，不调用API；新增入口不得通过强制重载绕过现有保护。

## 参考边界

目录文字、行高、缩进和选中态参考用户提供的旧版截图。顶部书名位置及后面三个顶层入口遵循用户随后确认的七项结构。旧图只显示②、③，本实现不自行增加①或其他编号。
