# 提示词组合执行与失败恢复

## 边界与原因

组合页服务于提示词维护和试验，不是小说生产入口。作者选择已有组件的精确版本、排列和启停，填写中文参数，明确参考书籍与资料；不会自动复制组件正文、默认送出整本书，或采用调试输出为人物、关系、规划、正文。

> 白话比喻：组件分类像书架，配方像借阅清单，冻结预览像已经封好的快递。对应到系统：移动分类不改变旧配方引用；参数变化需要重新封装预览，不能把新内容塞进已经提交的请求。

> 速记方法：先保存组合，再预览，最后明确试运行；试运行只读结果、不写小说。

代码拥有六类受控 PromptAsset、真实输入与输出规格、系统消息和执行政策。普通组件的信任标签不授予系统指令权限；组件正文与变量仅放在补充用户消息。发送前按冻结任务输入重新编译，比较完整消息、输出规格、资产版本和生成政策，不让数据库中的普通内容替换代码合同。字典字段按当次节点范围和精确版本冻结可选项，结果还需通过字段与选择数量校验。

## 唯一事实与版本

组合沿用配方／配方版本／槽位／组件引用／发布记录；上下文沿用清单与精确来源条目；预览、任务、步骤、尝试、状态事件和用量沿用既有账本。调试输出仅在一次运行尝试的终态保存，不建立第二套小说事实。持久化结构详见 [组合事实合同](prompt-composition-facts.md)。

输入冻结合同采用已通过真实 PromptAsset 校验的具体任务输入的 `const`，同时保存真实动态输出规格。这不是允许浏览器提交任意 JSON 合同的接口。任务模型路由来自新设计已发布设置；模型未配置仍可保存并查看阻断预览，不借用旧项目配置、不伪造试运行成功。

字段的类型版本和字典节点版本保存在冻结输入中供追溯；组装模型消息时移除这两项内部版本元数据，只发送字段规格与已限定的可选项，避免把全部节点版本标识当作额外上下文增加请求体积。

## 失败的具体处理

| 失败阶段 | 保留什么 | 用户在哪里处理 |
| --- | --- | --- |
| 读取目录／参考资料 | 已保存版本、当前编辑、书内资料 | 组合页重新读取目录，或重新选择参考书籍 |
| 参数校验／生成预览 | 组合版本和本次填写；尚未发送模型 | 组合页查看中文问题项目，修改后明确重新预览 |
| 模型路由／凭据 | 冻结输入和旧版本；没有已确认生成结果 | 点击“打开模型设置”，保存并启用后回组合页新建预览 |
| 保存或提交回执不明 | 原请求标识、当前编辑和旧记录 | 组合页“核对服务器结果”，不用新标识重复创建 |
| 模型输出校验 | 冻结输入与运行记录；不会采用不合格回复 | 查看具体失败步骤，处理后生成新预览；不因内容不合格自动换模型 |
| 保存试运行结果 | 模型调用已结束、冻结输入与运行标识 | 按原预览“读取试运行结果”；不把保存失败当成可安全重跑模型 |
| 服务进程中断、仍显示处理中 | 原领取记录与精确请求；不自动再次模型调用 | 读取并核对旧记录，明确新建预览才开始另一场试验 |

> 白话比喻：付款后小票没打印，不等于没有扣款。对应到系统：回执未知先凭原请求查账；只有确认结果后才能决定下一步，不能因页面读取失败就重复调用模型。

> 速记方法：未知先查；保存与读取分开；旧预览只执行一次；恢复在来源页。

保存成功后目录读取失败，界面保留已确认版本与凭证，明确失败的是读取。任何参数或组合编辑改变，旧预览不可直接运行。运行记录只查看和跳回来源页，不提供重试、采用或继续等修改动作。

## 用量与来源

记录实际调用模型、备用路径和尝试轨迹。只有上游真实提供输入／输出计量才能登记相应数字，未报告时保存空值，不使用请求字节估计冒充真实 token，也不虚构成本。输出不合格但上游已报告用量时，失败轨迹保留其真实计量。

## 模块与验证范围

- `src/client/promptComposition/`：中文参数、分类选择、草稿保护和明确恢复。
- `src/server/ai/composition/`：类型化输入组装、只读实际来源、受控编译与冻结重放。
- `src/server/http/promptComposition/`：固定恢复入口、提交与结果保存的阶段区分。
- `src/server/database/promptComposition/`：唯一事实、原子发布、严格幂等、单次领取和终态保存。

代码层、真实 PostgreSQL／HTTP、真实模型、用户界面验收分别记录，不互相替代。此文描述设计合同，不代表真实模型或全站恢复验收已经完成。
