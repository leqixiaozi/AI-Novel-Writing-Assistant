# 书籍工作区导航与编辑状态边界

## 结构与职责

书籍页面通过 `BookShell` 统一展示书名、书名旁的本书设置、左侧功能目录和右侧来源内容。功能目录按创作概览、故事设定、故事创作、完本与导出分类，消费 `BOOK_NAV_GROUPS` 与原 `BOOK_TASK_NAV` 路径。不得在同一书籍壳中另加一套顶部功能菜单。

> 白话比喻：目录是书架标签，编辑区是书架里的原稿本。对应系统：功能目录只定位原业务页面，不建立新的资料、正文或保存器。

> 速记方法：分类管导航，来源管编辑。改变菜单结构不改变业务正本和采用规则。

## 折叠与离开

左栏的独立按钮向左收起为 44px 窄栏，并始终提供展开入口。隐藏使用 `hidden`，不是条件卸载；右侧内容不依赖折叠状态。目录节点按书籍 ID 稳定构造，折叠操作不重建树，不修改 URL，不调用业务接口，也不隐藏右侧错误及恢复操作。

折叠偏好按本书 ID 保存在浏览器会话存储，存储拒绝访问时仍能在内存中展开或收起。偏好不是草稿备份，不是数据库同步数据。节点使用原生链接，页面离开继续受来源组件的草稿与未知请求保护约束；不能把折叠安全性理解为所有跨页面离开都不会丢失未保存内容。

## 两种树的区别

功能树定位页面；全书总纲、卷、章、场景对象树选择真实规划对象。两者可以复用 `TreeNavigation` 的显示组件，但不得混淆选中 ID、编辑范围、保存或恢复流程。

> 白话比喻：楼层指示牌告诉你去哪个房间，房间里的文件目录告诉你拿哪份文件。对应系统：页面导航与规划对象选择是不同操作，不能互相替代。

> 速记方法：功能选页面，对象选资料；目录展开不等于切换编辑对象。

桌面在书籍壳实际宽度达到 800px 时左右排列；更窄时上下排列，避免把编辑表单挤成窄列。内部编排分列依据内容容器宽度，不依据整台屏幕宽度。全部配色使用既有语义主题变量。

## 验证边界

本项仅完成源码静态 review 与待执行用例维护。类型检查、构建、自动化测试及交互验收未执行，整批授权任务完成编码后统一测试。导航整合不代表同页五视图或图谱操作已完成。
