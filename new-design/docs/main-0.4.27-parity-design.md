# 旧版 main 0.4.27 增量复刻设计

## 目标

把旧版 `8effbcdb..0f99cbb8` 中对新版仍有意义的功能语义补进独立的新设计系统，不复用旧版 Prisma 表、SQLite 数据、API 或运行状态。

## 已有能力

- 新版漫画角色设定已经包含 `gender`，不增加重复字段。
- 新版漫画场景已经是独立 Bible 实体并包含 `sceneType`，不复制旧版 `ComicScene` 表。
- 新版分格已经包含 `sceneRef`，不增加第二个场景引用字段。
- 共用顶部导航已经显示中文名“AI 小说创作工作台”和英文名“Biz Novel Studio”。

## 本次新增

### 漫画视觉资产

在 `112_comic_bibles` 的角色／场景实体上增加独立的视觉资产聚合。资产与版本、采用事件分离：上传只生成候选版本，作者明确采用后才更新资产当前版本；旧版本和原上传回执不可改写。每个版本绑定当时精确采用的 Bible 版本，避免角色或场景设定变化后图片失去来源。

图片只接受 PNG、JPEG、WebP、GIF，单文件不超过 10 MiB。服务端重新解码 Base64、校验文件签名、计算 SHA-256 并以 PostgreSQL `bytea` 保存；列表不返回图片正文，图片内容通过受控只读端点取得。漫画项目可由原创文本建立，因此不借用以 `book_id` 为所有权边界的小说视觉资产表。

### DeepSeek 结构化输出

新版继续把 DeepSeek 当作显式配置的 OpenAI-compatible 服务。仅当端点主机为官方 `api.deepseek.com` 或 `deepseek.com`，且模型是 `deepseek-flash`、`deepseek-pro`、`deepseek-v4-flash`、`deepseek-v4-pro` 或 `deepseek-reasoner` 时，在结构化请求中发送 `thinking: { type: "disabled" }`。其他兼容服务和模型不受影响。

## 不新增

- 新版没有旧版“题材／推进模式推荐返回资源 ID”的同构接口；当前开书 AI 返回完整方向对象，不接受候选资源序号，因此不加入无调用方的序号映射。
- 新版尚无短剧工作台，本次不增加孤立的短剧肖像和三视图字段。
- 不自动采用图片、不自动绑定分镜、不调用真实图片或文字模型。

## 生效与门禁

新增 `114_comic_visual_assets.sql`，继续作为手动迁移。代码接线、隔离库验证、作者库安装和页面验收分别记录。作者库安装前必须停止新版写入、创建完整备份并在独立数据库恢复验证；随后按 `108` 至 `114` 顺序安装，旧版数据库不操作。
