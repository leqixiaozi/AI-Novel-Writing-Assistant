# 跨书导演总控台

这是原书籍、导演范围、运行记录与质量问题的只读组合视图，不是另一套任务队列。像查看各车间的生产看板：看板显示原工单的进度和所在工位，处理仍回原工位，不在看板偷偷重新开工。

## 接线

- 公共合同：`common/directorFollowup`。
- 应用：`getDirectorFollowupWorkspace(filter)`、`getDirectorFollowupDetail(kind,id)`。
- HTTP：`directorFollowupRouter()`，挂载 `/director-followup`。仅 GET `/workspace` 与 GET `/records/:kind/:id`，详情 `id` 为原 UUID，不是列表的 `kind:id` 复合标识。
- 客户端：`DirectorFollowupPage({api,initialBookId?})`，建议入口 `/new-design/operations/director`。失败导航固定本入口，按钮名“返回导演总控台”。
- 中央 API、路由和菜单由根任务接线。本模块不编辑这些共享文件。

## 正本与范围

书籍统计读取 `books`、`ai_tasks`、`production_director_runs`、`quality_issues` 和原检测报告。跨书记录复用 `authorTasks` 原投影，沿用原中文状态、失败阶段、已保存证明、请求凭证和来源路由。一次查询使用同客户端 `REPEATABLE READ READ ONLY` 事务，公共运行记录 facade 只在该客户端读取，避免同屏读到不同时间的状态。

统计是原记录数量，不是互斥任务数，更不是章节完成度。书籍目录最多100本且明确截断；指定书籍单独按真实 ID 读取，目录外也不会换一本书替代。目录状态筛选只控制目录，跨书记录保留原范围；记录筛选由原运行记录合同执行。

详情冻结版本展示实际合同、清单、模型快照、配方、计划、问题描述和检测正文指针。哈希来自原版本账本；资料检测范围使用原报告保存的快照哈希并明确标注，不冒充资料版本内容哈希，不用展示数据生成哈希冒充版本哈希。不读取正文、模型回复、凭据或原任意错误文本；无原哈希明确留空。最多100步、1000条引用，导演章范围最多500章，检测正文、规划和资料各最多200项，所有显示截断都明确提示不是全量冻结输入。

来源导航保留原路径及是否精确，拒绝外站、跨书路径或书籍参数、敏感参数和控制字符。无法核对时指向真实运行维护页，不冒充已选中的章节或问题。前端晚到的不同记录回包不能替换当前所选详情；筛选页不含当前记录时保留原详情，不自动选第一条。

## 没有批量执行

本模块没有写事务、模型调用或任务操作。原租约过期不证明模型未发送；未知结果、作者暂停、冲突和陈旧范围必须回原来源核对。现无统一跨来源的完整低风险恢复预览及逐项原回执，所以批量恢复明确不可用，不用目录刷新、GET 空结果或已有其它章节结果当作恢复证明。
