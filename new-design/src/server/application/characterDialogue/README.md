# 人物模拟应用边界

公共入口见 `index.ts` 和 `common/characterDialogue.DialogueApi`。原书/原会话/原回合 UUID 均显式校验；原来源不可读时不选择其他记录代替。所有 GET 只查原来源与回执，不调用模型，不终止原任务。

把原凭证理解成快递单：核对同一单号只能确认这件包裹，不能另寄一件冒充恢复。对应到代码，同键必须匹配完整作用域和输入哈希；恢复已存回复不重新调用模型。速记：**查旧键，不造新单**。

自有 Prompt 由专属发布合同冻结 `schema.const`；模型只获得发言人物本人私有历史，以及该沙盘先前成功回合的公开发言。动作只能引用这次输入中的精确认知/状态 ID。明确选择动作通过原规划同事务 façade 保存草稿，不自动采用、不写正式结算。

当前未执行任何运行验证，数据库/受控 provider 单次执行/浏览器来源恢复留待完整批次集中验证。
