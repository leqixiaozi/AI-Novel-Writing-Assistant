# 人物对话模拟：非事实沙盘

本模块只存模拟会话、原回合回复和明确选择动作的技术回执。人物档案、状态、认知、章节正文和规划版本仍分别来自原模块；没有第二事实库。

像演出排练：演员拿到某一幕的本人台本，听见排练中的公开发言，但排练不会改变已经出版的故事。对应实现为稳定章 `checkpoint`、当时真实资料版本、本人章节认知和状态；他人只提供公开姓名，不把其私有认知放进本轮 Prompt。速记：**定章 → 验源 → 一轮 → 审阅 → 明选**；模拟不等于发生。

## 历史与限制

读取原稳定检查点、已采用且未归档的正文、已提交结算及精确资料历史版本。状态重放原初始版本与该章范围内的原变化，认知只读取原确认变化和真实章节版本，不读取当前状态投影。每条认知保留原命题 predicate、真实 subject/object 身份及截至章名称，而不是只传一个脱离语义的布尔值；不读取这些对象的私有认知。未锚定章节的认知不混入；缺失不等于不知道或客观真相。manifest 使用原 resolver 的真实档案/初始状态/变化/认知/正文哈希，结算原来源另建原依赖硬边，发送前再核对原范围，不能用显示表单哈希冒充原版本依赖。

关系类型没有独立不可变的历史规格版本时，检测到涉及所选人物的当时关系即诚实阻断该来源；不把当前规格或时间戳假装成历史证明。没有关系的可证范围可准备沙盘；这不意味着全站所有人物范围已可运行。资料扩展缺少历史规格证明的部分不使用当前定义补齐。自由文本模拟仍须作者审阅，不承诺语义上完全没有幻觉。

## 原请求、模型与规划

会话、回合、选择分别保留 UUID 原键及完整输入哈希。回合仅领取赢家调用一次原受控 `character_dialogue` 路线：自有资产 `new_design.character.dialogue@v1`、真实发布合同/配方、原 manifest/snapshot/task/attempt/usage。禁止自动重试和备用路线；未配置只是配置阻塞，不假报实测可用。

发送状态与实际执行回执区分：收到不合法结构仍是收到回复，保留真实用量；发送后断线才是未知。已保存回复可明确完成原回执；过期回复只读保留，不作为可选动作。未知原回合 GET 不重发；真实租约过期可明确结束原未知运行，保留未知用量，迟到回复不覆盖。

只有作者勾选原成功回合的动作，才在同一事务调用原 `addPlanningVersionInTransaction` 写入规划独立草稿约束和原保存回执。保留其他正文、规划字段、父级依据、执行模式、精确引用；不正式采用、不结算认知/状态。重复约束拒绝，不为 no-op 修改历史。

纯数据库操作只有同锁成功核实原键不存在、COMMIT 未开始且 ROLLBACK 收到确认，才可返回本次 `not_written`；原键冲突、读取失败、提交未知均保留原键。恢复旧未知保存仍保留完整输入，不把局部回滚当旧请求不存在。

## 尚未验证的边界

本轮仅编码与静态审阅，SQL083 未运行。数据库原来源跨模块并发、触发器、租约、实际浏览器与真实模型均待集中验证。回复先持久到原回合表再完成原账本；若模型已返回但该原回复首次数据库保存失败，内存回复没有本模块额外本地 spool 保证，不能宣称重启后仍可恢复它，也不能重调模型。初始领取回滚且响应丢失时，GET 阴性不能解锁；没有可读租约的旧未知凭证保留并阻塞，不冒充全站恢复闭环。坏存储或缺身份旧凭证只有诚实维护导航，不声称维护页能自动查看/修复它。

基础设施测试可用 `withDialoguePool` 注入独立池，HTTP 不接受连接、provider 或执行器覆盖。
