# 人物与作者谈话

书内单个人物按当前档案、当前关系及其原端点版本回应作者。采用正文存在时必须明确截至章；已发生正文、本人确认认知、人物及关系状态均限定在该章内。当前档案与关系设定不冒充截至章的历史事实；没有正文时使用档案与初始设定，无需第二个人物或稳定结算点。

独立 `character_author` 提示词通过原 `character_dialogue` 模型路线冻结合同、来源清单和模型版本。技术回执绑定原任务、步骤、单次尝试及真实用量；同键重读不调用模型，同人物未知请求阻止换键提交。历史必须完整匹配同一来源已保存回合。回复先写既有安全原子凭证，再保存数据库；恢复只续存已收到的原回复，过期或来源变化保留旧来源候选，不修改正式状态、认知或正文。统一已有回复恢复页接入此来源。

`101_character_author_trials.sql` 为默认关闭的手动迁移，不加入普通启动注册，不在作者库安装。关闭能力后原回执仍可读取，新的模型请求拒绝。客户端原消息和请求逐项校验、独占核对并保护跨页切换。
