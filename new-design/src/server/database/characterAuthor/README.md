独立v2回复在原谈话成功输出中保存结构化倾向草稿和证据；旧v1基础回复仍有效，不推断不存在的倾向。102手动能力默认关闭，不注册启动。明确带入生成原正常作者资料GUIDE版本及不可变决策回执，不带入／撤销亦保存原选择；来源、原键、候选和版本完整核对。窗口最多三连续未来章，来源变化、到期或撤销停止上下文消费；生成候选不消耗使用额度，同章改稿及窗口内后续章可复用。
