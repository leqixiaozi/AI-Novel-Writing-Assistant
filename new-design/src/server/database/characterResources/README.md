# 人物资源账本与章节回填

资源页读同一份本书人物、正式人物到道具的关系和正式状态来源，不建立持有副本。用户必须明确选择实际已发布关系及其非派生状态维度；配置没有该合同则保持空账本，不将普通创作关联、图片或档案文字当作持有。关系填写仅在展开项中显示，不充当当前状态；初始版本或已确认结算来源未通过校验时保持未知，数量 0 和 false 是有效值。

> 白话比喻：资源页是查账窗口，关系填写是开户资料，正式持有来自确认过的流水。对应代码：只读组合使用 `readProfessionalState` 的真实来源校验，候选保存仍交由原章节结算模块。

> 速记方法：先选真实维度，再读确认来源；未知不猜，候选不入账。

## 所有权与事务

`getCharacterResources` 在 repeatable-read 只读事务中读取本书正式关系版本、公开字段规格与本书扩展、真实状态、同采用正文的未确认候选和最近五章。读取接口在研究恢复中间件之前退出，不触发任务恢复。`freezeResourceBackfillScope` 在调用方的同一模型领取事务中核对人物版本与 revision、明确范围内资源和关系版本、已知前值及采用正文锚点，再缩小既有结算 catalog；完整规格哈希保留，不将子集伪装成另一套规格。模型快照另经 `verifyFrozenResourceBackfillScope` 重读本书真实来源。

受控 PromptAsset `new_design.character.resource_backfill` 使用原章节结算的字段类型、基线、字典节点与 UTF-16 原文位置验证，只允许明示资源和持有关系；不存在的数量不自动初始化。执行仍使用真实 `chapter_settlement` 模型路由、任务合同、上下文、尝试、用量和单次领取记录。输出导入原 `chapter_settlement_items/state_change_proposals`，正式状态只在原章节人工审阅并结算后改变。

## 完整原请求与恢复

客户端在发送前持久完整请求（会话、revision、完整规格哈希、人物版本、维度、资源和关系范围、原请求键）。只读 POST `.../editing/ai-extraction-receipt` 比较完整原输入哈希，不根据当前最新章节或最新列表猜结果；同键不同范围拒绝，空回执不证明未写入。已确认保存后读取失败保留原凭证。尚在运行或原模型结果待导入时只返回原章节处理；刷新、核对和已保存结果导入不再次生成。页面离开需处理 dirty/locked 状态，迟到读取不发送新的模型请求。

## 手动存储合同

055 的原存储守卫固定只接受章节提取资产，资源专用资产需要 [085 守卫迁移](../../../../migrations/085_character_resource_backfill.sql)。此迁移**不注册普通启动**，只替换同一函数，保留 OID、触发器、列和全部历史；新领取要求真实采用正文、人物版本、资源与关系版本、正文锚点及相同受控配方输入，旧领取和模型结果不可改写。代码同时检查登记和实际守卫能力，未安装或已回退时在调用模型之前说明未写入。

仅新空隔离测试库应用迁移。用户／开发库应用必须走已有维护安装边界：先验证备份可恢复，明确安装，事务内执行实际 SQL、登记原迁移并核对函数和既有回执。回退前先处理在途资源请求，使用 [原055守卫恢复文件](../../../../migrations/manual-rollback/085_character_resource_backfill.sql)；历史登记与业务记录保留，能力检查识别已回退。此文档不代表已在线安装或授权本任务修改用户库。

## 完成边界

当前闭环覆盖**可编辑结算会话的确切采用正文**，读取最近五章、明确单章和资源范围准备候选、人工确认与普通结算；资源策划字段及读者／持有人确认认知已有实际来源。稳定会话不能直接重开；稳定章节补充结算、批量最近章节、角色定位对应显示范围和叙事用途专用候选仍未完成，不据当前账本宣称整个旧版资源页等价。稳定章节需明确下游影响方案及保留历史的补充闭环，继续在原队列实现。

隔离验证使用完整实际迁移、新空库的正式关系发布与实例、初始 0/true、规划及采用正文、真实锚点、实际模型路由快照、stub structured provider、候选导入与人工结算。另验证不同原范围、伪造版本／正文、不可变模型结果、只读 HTTP 无任务或档案新增、原055守卫回退后历史可读。没有在线模型、用户书写入、重启或浏览器验收。
## 资源策划与认知

叙事用途、策划摘要、预计使用起止章序和限制通过资源规格的明确预览、发布与逐书安全新增提供，全部可选且结算策略 none。原道具表单拥有编辑与保存；账本仅展示真实已安装字段和值，不能把普通局部同名字段自动当成标准用途，不能把策划转成已发生事实或持有状态。

读者与当前持有人所知分别从认知领域的确认投影读取，核对实际来源、正文及对象；怀疑、误解与知道分别展示。没有记录保持未确认，不推断未公开。命题可以资源为主语或真实引用对象，读取在数据库侧限制本书与当前人物范围，超出清单标记不完整。
