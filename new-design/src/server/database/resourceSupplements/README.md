# 稳定章节资源补充

稳定会话保持终态，不重开、不重新采用相同正文，不复制新正文代替历史。

本模块先提供只读基础合同：从本书当前有效的稳定检查点读取原采用正文、原计划版本、准备、采用、会话、结算以及完整确认事实／认知／状态来源。原确认清单缺失或来源失效时拒绝补充，不丢弃旧记录。所依据的是正文的冻结计划版本；后来的计划编辑不能静默替换正文来源。

历史前值截止于所选稳定章的末尾，包含该章已有确认变化。查询真实有效结算、原状态变化和正文证据，不读取全书最新缓存。没有正文状态时，仅读取在原检查点形成前已存在的不可变初始版本；后来新建或修改初始状态不能反向填充旧章。0、false 和未知分别保留。调用者负责同一只读可重复读事务。

这两个入口均只 SELECT，无 HTTP、页面按钮、模型调用或启动迁移。独立补充会话、原请求回执、合并确认清单的补充结算、下游影响冻结与逐项复核还未接通，不能据本基础合同宣布稳定章回填完成。

旧操作映射：旧人物资源页选取稳定正文回填 → 新人物资源页原采用正文入口 → 原稳定终态不可写及早期章前值被最新状态污染的缺口 → 本阶段核实原历史及章末前值；完整按钮仍需接入受控补充、确认、结算与下游复核。

## 手动存储基础

087不加入普通启动迁移。它允许独立准备／补充会话引用实际原检查点和原采用记录，保留原正文、稳定终态及committed结算；补充原完整输入、冻结来源和回执必须同事务持久。原回执不可修改，原检查点只允许状态变化，不能改确认清单。普通首次采用／切换的唯一约束继续成立。

补充结算的延迟守卫核对同一事务继承原检查点、原结算仍有效及完整确认集合，拒绝丢项、重复或伪造。它仍无条件拒绝正式补充提交，因为实际下游完整性复核尚未接通；operational=false有数据库约束，改一个标志不能绕过。普通编辑命令和受控AI领取也按真实补充会话类型关闭，原读取保留。新补充不得回溯建立初始状态，不得复制原事实为新增资源候选。

087仅在新空测试库安装和验证，没有HTTP/UI入口。后续需实现补充生成、结算和下游复核，再通过另一个明确手动合同替换关闭守卫；不能直接删掉保护或翻标志开放。见[安装与保留历史边界](../../../../docs/wiki/resource-supplement-history.md)。

## 资源预览与完整原请求创建

`previewResourceSupplement`冻结真实人物／道具／持有关系的确切版本和正文锚点，复用正常已发布字段清单，所选字段前值由同事务的章末历史源替换。源帧按实际可持久JSON计算哈希，包含原确认来源、字段／字典规格、关系和历史值。后续章节的真实数量／持有变化不会污染该帧，缺源仍未知。预检共享已验证基础，避免每个字段重读全部原确认历史。

`startResourceSupplement`是未挂HTTP/UI的内部命令，只创建关闭中的独立会话。完整书籍＋输入哈希、原输入、来源帧与回执在同一事务保存；原请求锁和书级锁在SERIALIZABLE快照前取得。复用原采用记录、消费独立准备，记录session_started，不伪造body_adopted，不改变正文指针或正式状态。归档后原回执仍按完整原输入读取，不由当前可用字段补齐。不同输入或原读取中断保持unknown；提交开始后的异常也保持unknown，确认回滚且完整原查无记录时才为not_written。finally不覆盖原结果，释放失败销毁该连接以解除会话锁。

结算模块拥有补充只读视图，读取并校验冻结原帧／原回执，显示历史前值，不读取全书最新缓存来重建；旧不完整帧拒绝读取。原会话正常视图仍不变。SQL领取守卫也拒绝未开放补充，从而保护旧缓存代码的调用路径。正式补充、模型调用和页面入口仍未开放；完整业务需注册专属历史来源提示词、受控候选／人工确认、合并结算和实际下游复核。

专属历史来源提示词现已注册；内部AI模块的只读准备方法从结算门面的完整原帧读取，不重建当前状态。普通生成入口不接入该任务，SQL领取和编辑／结算仍关闭。详细合同见wiki；提示词注册不等于业务可用或允许安装用户库。

手动088（未注册启动）接入受控候选领取／原模型结果导入及正常人工创建／编辑／确认，复用既有任务、尝试、用量和全输入原回执。门禁校验当前实际资源规格及原确认来源，前值仍为冻结章末值；旧正文计划固定而不跟随后来的采用版本。仅候选可用，正式结算／回溯初始仍关闭，087下游闭环守卫及operational不变。停用保留完整记录和原结果。详细安装条件和业务缺口见wiki；只在新空库使用模型请求桩验证，无用户库安装、在线加载、真实模型或新增HTTP/UI。

`downstream/`拥有只读结算影响预览，消费正常结算门面的实际候选／领域／确认来源，冻结后续真实采用正文、原正文计划、当前计划、确切引用和字段状态链。哈希涵盖完整来源，无法把丢失证据或过期计划解释为空影响。它不写复核标志或正式结算；合并、复核日志、有效源阻断与实际解除仍待实现。
