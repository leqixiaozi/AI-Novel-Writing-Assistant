# 稳定章节资源补充

稳定会话保持终态，不重开、不重新采用相同正文，不复制新正文代替历史。

本模块先提供只读基础合同：从本书当前有效的稳定检查点读取原采用正文、原计划版本、准备、采用、会话、结算以及完整确认事实／认知／状态来源。原确认清单缺失或来源失效时拒绝补充，不丢弃旧记录。所依据的是正文的冻结计划版本；后来的计划编辑不能静默替换正文来源。

历史前值截止于所选稳定章的末尾，包含该章已有确认变化。查询真实有效结算、原状态变化和正文证据，不读取全书最新缓存。没有正文状态时，仅读取在原检查点形成前已存在的不可变初始版本；后来新建或修改初始状态不能反向填充旧章。0、false 和未知分别保留。调用者负责同一只读可重复读事务。

这两个入口均只 SELECT，无 HTTP、页面按钮、模型调用或启动迁移。独立补充会话、原请求回执、合并确认清单的补充结算、下游影响冻结与逐项复核还未接通，不能据本基础合同宣布稳定章回填完成。

旧操作映射：旧人物资源页选取稳定正文回填 → 新人物资源页原采用正文入口 → 原稳定终态不可写及早期章前值被最新状态污染的缺口 → 本阶段核实原历史及章末前值；完整按钮仍需接入受控补充、确认、结算与下游复核。
