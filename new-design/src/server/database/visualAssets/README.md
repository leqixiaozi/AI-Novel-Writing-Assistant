# 本书视觉资产正本边界

入口 `index.ts` 提供本书目录、受控图片上传、说明版本、影响预览、明确采用、准确绑定、归档、原键回执及精确图像读取。`withVisualAssetsPool` 仅用于基础设施隔离，HTTP 不接受池、路径、provider 或模型执行覆盖。

复用原 `assets/asset_versions/asset_content_objects/asset_content_integrity_checks/asset_adoptions/asset_events/asset_mounts/dependency_change_previews`。067 只在原事件、挂载和预览加入技术回执与完整输入哈希；不新建视觉资源、采用、正文或生成状态副本，不修改已应用迁移。版本保留真实来源，人工说明形成同图的新候选版本，不改已采用指针。

共享挂载／影响预览触发器会在普通知识引用写入时也编译，不能只在视觉分支认为路径有效。074 固定 067 三个原函数的 `pg_catalog, new_design, public, pg_temp` 搜索路径，不改变业务条件、事实或历史回执。白话像共用前台必须先找到正确楼层，才能判断来访者是不是办理照片业务；速记为“先找表，再分业务”。用户开发库不因此自动升级。

> 白话比喻：资产像相册，版本像每次保存的照片，绑定像把某一张照片贴到指定页。对应系统：采用只改变相册默认展示图，已贴到正文或资料的精确照片不会暗中更换。

> 速记方法：保存留候选，采用改当前，绑定定版本，归档留原图。

仅 PNG、JPEG、WebP、GIF，10 MiB 上限，完整规范 base64、二进制结构头、实际内容 SHA-256 与大小核对。原 local/managed_file 存储约束保留，受控路径 `data/assets/visual-assets/visual-哈希.扩展名`；API 不返回 locator。逐级目录、普通文件、非符号链接、打开句柄及实际内容再次核对；禁止 SVG、外部地址、目录穿越、任意磁盘位置。写入独占临时文件并同步后，以不覆盖的硬链接发布内容寻址文件；只清理本次生成临时文件。已登记坏文件不覆盖，数据库回滚不删除已保存原图。跨机器备份须连同 `data/assets/` 和数据库一起迁移，不能只搬 SQL 而遗漏图片。

同原书、资产修订、精确版本和原 key/fullhash 在同物理事务写业务事实与技术回执。影响预览记录真实依赖图，确认时重新核对修订、来源、目标和影响哈希；深度或数量未完整时拒绝采用／归档，不当作零影响。未采用候选的归档预览引用真实候选版本，不伪称已有采用；回退原历史版本按原账本记录 rollback。绑定只允许本书真实当前正式资料、已采用正文或本书本身，未来图片更新不改原绑定。

原 asset_mounts 不生成依赖图边，因此本模块在原预览 metadata 冻结真实挂载引用和哈希，确认时重读加锁核对，不假造依赖资源。067 的新增 active-mount guard 只对 cover/illustration 核对书籍与资产仍 active，并按 book→asset 锁序避免已审核采用／归档时晚到新绑定；原 owner／精确版本校验完整保留。既有 dependency_edges 生产者没有全域统一书锁，确认重算影响哈希后仍存在并发插边细小竞态：本轮明确静态风险，不擅自加全表锁或声称下游处理已完成。

> 白话比喻：手机断网不代表订单没有付款，先查同一订单。对应系统：只读 GET 空结果不是没写入的证明；完整原请求可明确完成同一幂等数据库操作，不再付第二单。

> 速记方法：未知查原单，完成用原单；读失败不清单，提交未知不猜测。

COMMIT 未开始且 ROLLBACK 收到 ACK 才证明本次数据库未写入；未知 COMMIT／回滚丢失仍 unknown。已有受控文件可能保留，不能把数据库回滚说成文件没保存。GET 只读；来源页明确同完整原输入／同 key/fullhash 完成纯数据库操作，先读正向回执，不用新文件代替，不涉及模型。只有 key 时只允许读回执。成功回执后目录读取失败保持正向保存事实。

图片生成由独立 `imageGeneration` 模块提供，目录能力只在读取到明确专属连接时开放；不会使用默认文字模型。生成后的受控单图通过 `saveVisualCandidateInTransaction` 复用本模块原候选写入链，来源为 `ai_generated`，元信息保留原 task、attempt 和连接版本；图片仍写入原资产版本，不自动采用或绑定。原本地上传入口使用同一写入函数，来源仍为 `upload`，不会被改称模型生成。连接存在不等于外部服务已经验收；本批只编码和静态审阅，外部图片调用未执行。
