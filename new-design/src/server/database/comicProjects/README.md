# 漫画项目来源

`109_comic_projects.sql` 是独立手动迁移；不随新版服务启动自动安装，不读写旧版漫画表。安装前须完成作者库备份及隔离恢复演练。

项目创建沿用旧版三种可用来源：小说导入、原创灵感、文本导入。小说导入只读取新版已采用正文，在同一事务中冻结章节、正文版本 ID 与当时文本；后续小说修改不会覆盖漫画来源。来源版本追加保存，不允许更新或删除。请求键唯一；结果未知先读取 `/comic/create-requests/:requestKey`，相同输入可沿原键重试，不能换键重复创建。快照保护触发器失效时暂停新创建，已有项目和原回执仍可读。

`110_comic_episodes.sql` 在 109 后手动安装。人工分集大纲先保存候选版本，再明确采用；候选和采用事件均不可改写，旧版重生成覆盖已保存话目的行为不会复现。候选、采用的原请求可分别按键读取。AI 大纲生成尚未接入。

`111_comic_panels.sql` 在 110 后手动安装。整话分格脚本的动作、对白、人物、场景和画面提示词一次冻结为候选版本；采用记录独立追加。旧分集大纲对应的脚本仍保留，但被标记为不就绪，不能当作当前大纲的脚本继续采用。手工脚本编辑可用；AI 生成、图片与导出仍未接入。

`112_comic_bibles.sql` 可在 109 后手动安装。漫画角色／场景文字设定有独立候选和采用版本；旧版角色三视图、表情图、服装／道具图以及场景设定图仍属后续图像资产阶段。新版本不覆写已采用设定。
