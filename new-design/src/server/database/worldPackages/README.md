# 公共世界包与书内安装

## 正本与边界

公共根使用既有资源空间中的正常世界卡片。固定版本包是实际card_versions、card_type_versions、表单、字典节点与关系版本的完整引用集合，独立持久的是发布／安装元数据和映射，世界资料没有第二套正本。六个同步分区的归属由作者明确选择。读取或预览不写待同步摘要，不生成模型请求，不移动安装基线。

`084_world_packages.sql`刻意不加入普通启动迁移。迁移默认operational=false；模块同时检查实际数据库约束触发器是否启用。作者库的安装、启用和现有服务加载分别验收，代码编译不能代替这些步骤。停用只更新能力开关，历史、映射及原回执保持可读，不删除表或冻结记录。

`108_world_package_archive.sql`也只允许在 `084` 之后手动安装。归档状态另存为只追加事件，不修改或删除公共固定包。普通目录隐藏已归档来源；按版本读取及既有书内安装来源仍可回看。新安装和同一公共根的后续发布在已归档时拒绝，恢复后重新开放。归档保护触发器缺失或停用时，目录继续隐藏已归档来源，但新安装、发布及归档状态写入均暂停；没有安装 `108` 的既有 `084` 系统仍按原世界包合同运行。

## 正常安装与原请求

每一本书建立自己的正常作者资料。逐对象预分配独立保存原键，精确公共版本、全部来源字段（含局部补充、null、空值、0与false）、本书实际规格和表单在只读预览中核对。缺映射、重复目标、未知字段及公共字典节点不能直接复用的值拒绝。保存复用`createAuthorMaterialInTransaction`，全包卡片、作者回执与安装映射在一个物理事务内提交，不按重名合并，不写正式事实、状态、认知、正文或持有关系。

同一完整原请求返回原结果，原键不同输入unknown；原查询失败不能因本次ROLLBACK成功降为not_written。提交确认丢失只读核对原请求，无重新安装或新建请求。历史源版本被包引用后受数据库保护，普通更新通过新增正常版本继续工作；延后约束确保引用集合完整，不能提交缺项包或安装。

## 当前开发切片

基础历史验证覆盖固定版本及无关系包独立安装。后续代码已接入本书世界准备公共候选／明确首次发布、完整正常关系转移、字段／新增对象／关系的三方pull、push候选与独立发布、双方逐项基线和同步历史。来源页及完整原请求恢复已接线。归档／恢复在隔离库已验证，作者库安装、在线加载和页面验收须另核；不能用隔离验证推定作者页面可用。
