# 公共角色试用持久化边界

本模块只保存固定公共档案的单次请求／回复证据。原角色归 Card／CardVersion，图片复用 asset_content_objects 和 visualAssets 的实际内容校验／受控文件读写；本模块不创建书、不复制人物正本、不写规划、正文、状态、认知或正式事实。

`repository.ts` 负责事务、能力检测、确切原档案／局部字段读取、原任务锁及终态；`freeze.ts` 负责真实专属连接／路线、受控资产、原合同／配方／模型快照／上下文清单；门面负责原键领取、回复续存、图片内容引用和追加主图／归档事件。模型调用归 `application/publicCharacters`，HTTP映射归 `http/publicCharacters`。

领取在原请求锁与角色来源锁下持久原 Task／Step／Attempt 及完整冻结输入。重复原键先核对完整输入，直接返回原结果，不执行模型；新请求遇到该角色未完成领取即阻止。来源只允许原公共资源空间的角色及确切版本，包含原规格和局部字段版本／0值；书内人物不会自动公开。

专属试聊资产 `new_design.character.public_dialogue@v1` 复用已发布 character_dialogue 路线，禁止自动重试／备用路线。每条历史须是同一角色／版本／来源哈希的真实成功回复，并包含完整此前链。图片使用 `new_design.character.public_portrait@v1` 专属图片协议及确切图片连接版本，一次只生成一张；批量由客户端逐张编排。

两类有效模型回复先使用原安全文件凭证机制持久，再登记数据库回复和实际执行来源。凭证含公共范围、角色版本、请求、尝试和冻结输入哈希，严格核对全部身份与回复哈希。续存只能读原数据库／本地回复，不能调用模型；收到原回复后禁止将其结束为未知。未知过期终止仍保留未知用量；COMMIT前且ROLLBACK确认的本次新写入失败才是 not_written。

图片落入原内容对象前核对编码、结构、哈希、大小及实际文件回读；主图选择再次读取实际文件。主图／归档只是引用真实成功图片的追加事件，采用最新事件乐观核对，并以角色锁串行处理。无可用主图时首个成功结果追加主图事件；归档主图从其他实际可读成功图片选替补，无可用项保持空缺。归档不删除文件或旧事件。内容定位使用原 visual-assets 前缀，兼容历史定位，不另造图片仓库。

手动 `097_public_character_workshop.sql` 不纳入普通启动迁移，默认 operational=false。新增公共清单范围不伪造book，保存已安装范围约束与解析／依赖函数OID；原书级失效边／状态不承接公共资源，公共来源仍由原不可变清单和尝试明确引用。新清单、领取与图片事件受默认关闭和不可变保护约束；关闭后原回复续存、只读历史及已提交原键回放保持。

共享完整图片资料／中英优化使用独立098合同，原 portrait 输入附确切优化回执／原文或优化选择；冻结前重核实际完整档案和画面，无优化时沿用原图片合同。

双端编译、公共样本管理／导入及 workshop 隔离 PG 全链通过：试聊、真实受控PNG字节、原回复恢复零新增调用、图片主图／替补、中英优化发送、正式分类和书封面。夹具在新空库明确替换不支持默认路由，原保护保留；原步骤关联 attempt 必须推进 revision。作者库安装、真实模型质量、其余页面和作者验收仍待。
