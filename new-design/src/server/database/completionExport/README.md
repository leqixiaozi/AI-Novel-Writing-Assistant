# 完本与发行导出模块边界

本模块负责把既有正文、稳定检查点、质量、失效、任务和运行维护账本冻结为可解释的完本检查与导出清单。

- 正文仍以 `chapter_body_versions` 和采用指针为唯一正本，导出清单只保存精确引用与哈希。
- 完本事件、检查结果、导出清单、Release Gate 证据均只追加，不覆盖历史。
- 导出请求复用 030 Outbox 与后台作业；迟到执行器受租约和 fencing 约束。
- 正式导出只读取稳定采用版本；审阅稿必须显式标记，不能伪装为完本稿。
- 备份、恢复、私有运行时和 AI 任务继续复用 024、030—032，不在本模块维护第二套状态。
- HTTP 层只从 `index.ts` 使用公开入口。
