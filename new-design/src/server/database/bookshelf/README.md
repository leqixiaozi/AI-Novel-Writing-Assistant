# 书架读模型与归档边界

书架和阅读采用 REPEATABLE READ READ ONLY，复用 home 模块公开的事实查询与投影，不建立第二书籍链。全部未完成开书 session、有效 book 封面精确引用和归档书籍在同一快照读取。阅读明确区分 saved（每章最新非空未归档保存版，可含未采用候选）与 adopted（当前明确采用版），两者均不表示发布或完本。chapter_body_versions 没有 book_id；必须经 chapter_documents 同时核对 bookId、documentId 和 adopted_version_id，不能假设版本有此列。曾采用的历史版本通过 chapter_body_adoptions.to_version_id 排除，不能计为待采用候选。

归档使用原 books.status='archived'；恢复改为 active。没有迁移、永久删除、回收站清空或草稿删除。事务锁原 book FOR UPDATE，核对原 expectedRevision，变更状态并只增一次 revision；完全相同的转移重放返回已有结果，恢复后重放旧归档不能再归档。COMMIT 回执不确定时只读核对原状态转移。

归档门禁复用运行记录模块的事务内来源查询，拒绝运行、排队、暂停、待恢复及未知执行/回执占用。额外从 information_schema 核对所有已有 book_id/status 原生记录，覆盖未投影到运行记录的请求与后台作业；资源自身的 ready 不是活动任务，只有正式任务来源的 ready 阻止归档。失败及已结束记录保留；不代替用户取消、暂停或恢复任务。

本机单 API 进程的 HTTP 写请求共用生命周期互斥门禁，在途写请求期间拒绝归档/恢复，归档事务期间拒绝新 HTTP 写请求。book 路径及 body.bookId 写请求先拒绝归档作品。此进程门禁不代替多实例分布式协调；若支持多 API 实例或独立任务调度器，必须为原生写入者补充同一事务归档锁，并在领取任务时核对书籍 active 状态，再开放该部署方式的归档。归档前发现可恢复/在途任务时保持原状态并返回来源，不能隐藏作品后放任后台继续写。


## 阅读、直接下载及本书弹层

只读 TXT 导出在同一快照冻结正文、版本身份及内容摘要，返回稿件性质与版本清单。下载不会创建出版产物、采用正文或追加任务；指定章节不属于本书/所选稿件时直接拒绝，不能改选第一章。选中章节下载使用当前显示版本，整本下载重新读取明确选择的范围；不能给待审稿套用稳定完本标签。

本书推进详情在同一只读事务复用运行记录及用量账本公开查询。世界卡片名称只表示本书世界资料，不能当作旧版绑定世界；账本未知 Token/费用不能当零。目录有界并提供原 bookId 的后续页；精确执行详情核对 kind、id 与 bookId。驾驶舱操作复用完整导演原命令合同；提交前可靠保存完整输入，未知回执只读核对原键，确认未写入且核对后才重新准备。跨来源批量恢复仍受原合同能力限制，运行记录保持只读。

封面、驾驶舱、执行详情和导出选择在本书弹层承载，书架只保留紧凑摘要与入口。封面图库和 AI 填写切换时保持组件及草稿，不将切换当放弃；原视觉、图像、连接、资料优化操作未知时禁止关闭。多图准备沿用各张原请求，顺序保存独立键和全输入，未知结果时停止后续张数，明确继续剩余时不能越过调用中的原键。主封面和替补由原视觉事务承接，实际验证仍待完整证据。

`classification.ts` 只读唯一原作品约定及当前局部值；保存扩展原卡片局部字段后通过正常作者保存／完整原回执。长短篇只读唯一新鲜采用故事总纲的 storyFormat；发布分类不替代原 books.status，原创／续写不从知识引用猜测，平台沿原五个枚举。无原来源保持未设置，筛选 URL 保留实际选择。`review.ts` 按精确原正文版本读取原审校请求／报告／未闭合问题，区分尚无报告、审校中、质量债、需人工／重规划、过期及已审校。

本书健康与阶段用量在同一只读快照使用原后台账本和实际 AI usage 投影；未知 token／费用保持未知，阶段名称来自原任务合同。已有回复恢复在独立来源页核对并明确续存，运行记录只读。分类合同和阅读单元通过，实际分类保存／健康 PG 和新审校／体验页面尚待完整检查；公共夹具前置阻塞不算通过。

集成菜单从独立包入口读取导航常量时只加载导航和惰性页面入口；不能静态导入全套业务页，避免旧版菜单依赖新设计各工作区的冷启动。实际打开新设计页面时才装配页面模块。
