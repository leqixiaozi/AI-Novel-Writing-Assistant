# 作者运行记录聚合边界

入口为 `index.ts`：`listAuthorTasks` / `getAuthorTask` 只读取现有领域正本。基础设施隔离 `withAuthorTasksPool` 仅用于集中验证，不接受 HTTP 选择连接。HTTP 挂载 `authorTasksRouter()`；客户端 `AuthorTaskCenterPage` 只注入同名两读 API。

不建立任务复制表，不保存投影状态，不运行恢复动作。一个查询语句读取来源、过滤状态／标签、统计真实总数及最多 101 条分页记录。状态分组共用于 SQL 过滤与客户端 DTO 投影，不参与 AI 意图识别。

正文请求与章节变化提取请求的 AI 执行记录在总列表中去重，保留领域请求的具体来源。开书会话、准备批次、正式待采用规划是不同正本，不假称已采用或完成。旧累计批次保留历史；质量债是关注项，不升级为全书失败。租约过期仅依据数据库时间显示待核对／有输出待审，不修改原任务状态。复合分页凭证保留 PostgreSQL 微秒及种类／UUID，避免同毫秒记录漏页。

来源仅带公共 UUID、原请求凭证和保存证明；禁止暴露原输入、模型回复、模型配置、凭据、SQL 错误及文件存储路径。未保存证明不表示未发送模型。分页和详情读取失败不得修改任何正本。

稳定可定位入口：开书 `books/new?session=`、章节 `writing?chapterDocument=&session=`、规划 `planning#plan-`、本书研究采用 `research/reference-packs?book=&adoption=`、研究运行 `research/records?record=&version=`、原导出 `completion?export=`。后面三类通过共同严格 UUID／同正本查询合同定位，未匹配明确提示，不用其他记录代替；历史查看和作者草稿分离，精准入口不等于自动恢复。尚不支持具体对象选择的其它来源仍显式 `exact=false`。

生产导演 `production_director` 直接读取原 `production_director_runs` 和其冻结范围／当前原请求指针，联原 `chapter_writing_requests/ai_task_steps` 统计候选、模型回复、待补运行回执和警告数量，来源精确 `books/:bookId/director?run=原UUID`。所有等待／运行／暂停／待恢复／失败／完成／结束范围都可在列表显示，不依赖当前浏览器 URL。进度只计原候选数量／冻结章数，不宣称正式采用、结算或全书完成；未知当前章不能因以前其它章有候选而变成已完成。已保存原回复或候选待补回执时仅提示回来源核对，原请求与导演状态不改变。已有正文请求继续独立展示真实保存与警告数量，没有另一套导演正文正本。新增中文“有警告”标签和原状态过滤共用 SQL／DTO；警告、质量债不自动全书失败。

> 白话比喻：长途车站屏幕显示这班车前两站已经到达，不代表第三站断联时整趟车已经完成。对应系统：导演总进度保留先前章候选，当前过期未知原请求仍待核对，不能把旧保存证明套到新章。

> 速记方法：候选计进度，当前章定未知；警告看原章，决定回原范围。

原过期调用显式结束后，原请求为 `cancelled`、当前真实尝试为 `discarded/unknown` 且无已保存模型回复时，仍保留“待核对”标签及未知结果／用量说明。仅读取原尝试枚举，不匹配错误文案，不把释放占用冒充未发送或成功；导演失败状态中的此类原请求显示待核对，明确取消的范围仍显示已结束并保留待核对标签。

原章候选存在且 `boundary_completed=false` 时计入原章边界待确认数量。待恢复或过期范围有原回复／待补回执／待确认章边界时显示等待作者确认，不以候选已保存推断结构化质量边界已处理；正在执行的有效范围不因瞬时待确认边界而假称停止。

> 白话比喻：挂断无人接听的电话，只是停止等待，不能证明对方没收到来电。对应系统：显式结束释放租约，原模型结果与用量未知仍然保留。

> 速记方法：结束释放占用，不改未知证据。

> 白话比喻：大厅电子屏汇总各窗口的排队和办理进度，真正办事仍去原窗口。对应到系统：运行记录只投影各领域正本，采用、恢复和取消只能在来源页明确操作。

> 速记方法：记录看进度，来源做决定；有凭证先核对，质量债非停书。

验证用例位于 `tests/author-tasks.unit.test.cjs` 和 `tests/author-tasks-http.unit.test.cjs`。本模块阶段仅编码及静态 review；测试、构建、真实 PG 与 UI 验收统一由主任务安排，未执行不得记为通过。
