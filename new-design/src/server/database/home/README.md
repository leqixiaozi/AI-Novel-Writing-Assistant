# 首页只读事实边界

首页只能读取已初始化的数据库连接，不能在读取中启动数据库、迁移、恢复工作线程或调用业务命令。一次读取使用同一连接的 `REPEATABLE READ READ ONLY` 事务；全部 active 作品不分页、不截断。独立账本先按作品聚合，避免多表连接把任务、章节或问题重复计数。

必填字段采用规划中心同一填充规则：缺失、null、空字符串、空数组为空；false、0、空对象和空白字符串均属于已填。仅已发布卡类型当前字段作用于该类型的现存 active 卡，没有卡时分母为 0，不推断资料已备齐。

正文数量只统计 active 文档的有效采用版本；稳定数量要求稳定检查点恰好对应当前采用正文。历史稳定版本不能证明换稿后仍稳定。

`writableChapterPlanCount` 表示“可进入正文准备”的结构数量：三层已采用有效规划、章的当前卡版本、章依据匹配当前卷、场景和精确资料引用数量与有效性通过静态读取约束，无采用正文或在途请求。它不替代来源页的完整生产校验；连续性、知识冻结与模型可用性仍在用户发起生成时核对。首页不能声称保证可执行。

任务数量与作品数量分开。最新导演按创建时间选取原运行，过期租约单独标识；首页不能把过期运行宣称为仍在执行。创建会话只返回有限元数据和规范化 director 状态，不返回正文、输入载荷、租约或密钥。失败创建会话仍可从原页处理，因此不属于已完成会话。
