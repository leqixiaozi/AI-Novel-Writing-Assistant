# 公共角色固定版本导入

## 来源与独立人物

公共来源只允许新版已有资源空间的 active character 卡片与明确选择的 card_versions，类型须已发布。书内角色、其他内容类型和不存在的版本拒绝；不按重名合并、不迁移或自动公开旧版库。来源读取使用该版本的类型字段与局部字段版本，未使用当前公共卡片替代历史版本。

每个非空来源值（包括0与false）都须明确映射。重复来源、重复目标、未知字段、缺映射、与额外手填值冲突以及无效类型／字典节点全部拒绝，不静默丢字段。映射值可由作者明确调整；完整原值、目标值、字段名与输入均进入审计。目标是本书正常人物资料字段，允许作者资料中原本可填写的字段；这些字段值只是档案填写，不是 entity_initial_states、state_changes、canonical_facts、knowledge 或持有关系。人物默认可结算能力不是已确认状态，不应据默认tracked禁止姓名等普通档案填写，也不能据卡片值生成正式状态。

## 同一保存链与完整原请求

预览冻结公共精确版本、本书人物类型／活跃历史表单／字典来源与真实结算政策。提交重新核对同一完整预览，持有实际来源、书籍、类型与表单共享锁，使用正常 createAuthorMaterialInTransaction 与 store.createCardInTransaction 保存唯一新卡片和作者回执；字典快照与正常校验保持。字段出处和 resource_adoptions 的完整输入、来源、映射及结果在同一物理事务提交，无第二份人物正本。相同书／原键完整输入返回原结果，不同输入未知冲突；已用于其他普通保存的键拒绝，不能将旧人物冒充新导入。

仅COMMIT前且ROLLBACK确认成功的本次新写入失败是not_written。原回执读取不明、COMMIT／ROLLBACK不明均unknown；客户端在发送前持久原完整请求，未知只能原请求读取。接收结果须先持久结果与填写，再清理原请求凭证；存储失败保留原键。独立只读路由放在归档写入守卫前，归档后仍可核对原结果，但不能通过读操作执行新导入。

## 验证与生效

无需新增迁移，使用既有resource_adoptions JSON审计。空库验证保留真实迁移、正常公共／私有类型版本、字段扩展、原作者写入、并发原键、回滚、提交回复丢失及完整HTTP只读。用户库、在线服务加载、真实模型与页面交互验收单独说明。公共人物的创建／编辑／试用完整专用页属于I后续工作；C4只覆盖已有新版公共来源的字段映射导入。
