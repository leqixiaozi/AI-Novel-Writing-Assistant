# 导演范围与执行边界

本域只存原书、冻结章顺序及计划版本、原请求指针、控制回执、执行租约和章边界确认。候选内容、质量提醒、任务状态及进度从原章节请求／正文候选／AI 步骤派生；不拥有正文、规划、关系、状态或结算事实。

> 白话比喻：一张装订好的工单目录，每一页链接原工单，页角盖章代表该页判断已经处理。对应到系统：范围冻结引用，`boundary_completed` 仅确认执行判断处理，不复制质量事实。

> 速记方法：范围冻结，引用原单；回执不改，边界原子确认。

来源页明确命令按 run advisory lock 和完整输入 hash 串行处理；原 key 不适用于不同动作／范围。已保存回复和未补账本／未确认章边界优先纯原结果收口。新 token 使旧 worker 无法续领／改变边界，应用侧等待同范围旧 worker 退出再接新的明确继续命令。

暂停请求在当前章后生效，读取和轮询不解除。明确重规划判断保留本章候选并终止旧范围，不能因后续 pending 章存在而直接 retry 继续旧计划。只在已确认失败章允许新 key；尚未执行准备恢复复用原章 key，避免丢失准备回执后另建模型请求。

结束过期范围只初读指针，原章实际锁定／校验及终态事件交给 chapterProduction helper，统一 task→step→attempt→request，避免预先锁 step/request 的反向锁序。已保存回复、账本或章边界待补不能作为过期未知请求结束后重发。

原控制回执保存接受事实和修订，不复制整份运行状态；GET 返回原接受动作及当前来源状态。运行记录只读聚合能直接打开精确较早范围，不依赖当前页面 URL，不包含变更按钮。

本轮只编码和静态审阅，066 未应用，动态验证未执行。

范围只冻结作者显式选择的知识原件／解析版本／全文 hash 引用；不存第二份参考正文。每章准备在同一来源事务核对引用，进入相同受控 Prompt／manifest。真实连续性从原事实、状态、认知、关系及前章稳定采用来源读取，不能由范围计数或当前显示投影伪造。冻结知识失效会定位原知识来源，不切最新解析版。

原章未领取与真实过期是不同证明；只有原任务、步骤均 queued 且无历史尝试，才算未领取。结束范围拒绝在途未过期原尝试、已有回复及未补账本／边界。原范围来源链接始终保留精确 `run` 标识，较早失败范围不能被当前第一个范围替代。
