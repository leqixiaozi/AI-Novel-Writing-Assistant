# 知识索引与语义检索入口

`knowledgeIndexRouter()` 挂在研究恢复中间件之前。所有入口精确限定书籍与原操作 UUID；GET 只核对原事实和受控回复凭证，不启动模型、索引或研究恢复，也不携带“未写入”的结论。

原模型连接版本明确绑定嵌入规格；参考原件与解析版本明确准备分块；向量调用、原回复入库、分代构建与语义检索分别有来源页入口。数据库规格／准备／构建只转发原事务在同锁核实原凭证无结果后的可信回滚证明；向量调用最初领取事务只有同锁成功核对原凭证无领取、原尝试不存在、未开始 COMMIT 且确认回滚，才生成专属 `KnowledgePreparationError`。锁／查询失败、既有尝试和后续局部回滚不能证明原请求未写。后续模型和多事务恢复失败保守保持结果未知。本入口发送前输入校验另可证明未进入业务调用，不把内部校验异常当作整体无副作用。

无租约的初始未知准备复用原 execute／semantic POST，前置校验完整原分块身份或原选索引分代。来源页只读核对与显式恢复分开：恢复须确认真实后果，服务器在原 key／fullhash／锁下只允许首次领取者调用，已有领取只返回原结果。GET 阴性不是调用许可；旧缺身份的原凭据不补成当前版本，来源／分代失效时保留真实阻塞，不伪造取消或完成终态。

> 白话比喻：查询快递单只是在看原包裹走到哪里，不是重新寄一份。对应到系统：原凭证 GET 不会重发向量调用；保留回复入库只处理同一份已收到的向量。

> 速记方法：先核对原单，再完成原保存；调用未知不重发。原模型发送、回复收到和数据库提交是三个不同结果。
