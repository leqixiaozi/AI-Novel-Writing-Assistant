# 本书关系状态配置 HTTP 边界

只服务章节结算所需的正式关系字段、显式能力及维度。来源页负责中文选择、草稿、明确发布与只读核对；运行记录没有恢复写操作。正式定义继续归现有关系与状态表，配置草稿和回执不是第二份正式关系。

> 白话比喻：先改空白表样，再明确发给本书使用；拿旧申请号查是否发出，不能查询失败就再次发放。对应到系统：保存草稿不生效，发布须精确版本与明确范围，未知回执先查询原请求。

> 速记方法：草稿可改，发布需审，未知先查；接口校验不得剥离真实字段定义。

输入 schema 由章节结算 facade 导出，HTTP 不复制简化字段规格、不自动发布、提升能力或建立初始状态。无模型调用，不编辑时间线或因果。错误必须保留中文步骤和可执行来源入口；事务结果只有领域已确认回滚才可标识为未写入。
