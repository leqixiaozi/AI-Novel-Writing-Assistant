# 原章节回复本地凭证

入口 `index.ts` 导出 `writeChapterProductionReplyReceipt` / `readChapterProductionReplyReceipt`。由原章节执行器在模型成功返回后先写凭证，再保存原 `chapter_writing_requests.controlled_output`；HTTP、模型执行器和正式候选安装仍归主模块。本模块不访问数据库、不调用模型、不自动采用或另建正文事实。

> 白话比喻：收银台网络断了，先把原交易小票放进保险盒，恢复后核对原交易，不再刷一次卡。对应系统：本地凭证保留实际已收到的原模型回复，不证明数据库已经提交，更不能作为重新调用模型的理由。

> 速记方法：收到先留凭证，原键核对正本；本地有票，不等于数据库入账。

## 精确合同

写入输入：`{bookId,requestId,attemptId,inputHash,output:ChapterGenerationOutput,execution:Record<string,unknown>}`。读取输入仅前四个冻结引用；UUID 与 64 位十六进制输入哈希严格校验。输出 `ChapterProductionReplyReceipt` 包括合同名、四个引用、原输出及白名单执行、三个独立完整哈希。写入返回真实已发布凭证；读取缺失返回 `null`，缺失不证明模型未发送或数据库未提交。

正文上限 200 万字符，与原章节 Prompt 合同一致；100 条警告，每条 2000 字符，理由 4000 字符。整个 UTF-8 凭证最多 16 MiB。用量保留真实整数或 `null`；不把未知值写为零，不冒充估计为实际计费。白名单仅服务类型／模型名、原配置快照引用、输入／输出／已知 Token、重试／备用计数、用量状态和原尝试的发送／接收凭证。没有地址、凭据、环境变量、配置层、消息、原技术错误或原始传输文本。成功必须有真实已发送且已收到的末次成功尝试。运行时未提供配置快照哈希时保存 `null`；调用方可传入已冻结真实哈希，不推测生成。

## 文件安全和耐久边界

受控位置 `new-design/data/ai-receipts/chapter-production/<bookUUID>/<requestUUID>-<attemptUUID>.json`，不接受外部文件路径。逐层检查普通目录、真实路径及非链接；只读取普通单链接文件，核对打开前后的文件身份、大小、完整 UTF-8、精确引用及全部哈希。读取用受控大小的定位缓冲区，不能因并发增大文件无限分配内存。独占临时文件、文件同步刷新、硬链接不覆盖发布、清理自身临时文件；同原引用／同内容返回原凭证，不同内容拒绝替换。

POSIX 平台同步新目录的父目录及发布目录。Windows 的 Node 无法可靠打开目录进行 `fsync`，文件内容仍必定 `sync` 后发布；不能宣称突然断电时目录项的物理落盘保证。进程崩溃若留下两链接的临时／已发布文件，安全检查拒绝把它当作正常凭证，不自动删除原文件或伪造成功。具有目录写权限的外部进程并发替换祖先目录属于已有 Node 文件 API 无 `openat` 的竞态边界，检查立即关闭非受控路径，部署应限制目录写权限；不承诺抵御管理员任意修改磁盘。

## 恢复与备份

数据库原回复缺失时，来源页可以使用已确认的同书／同请求／同尝试／同冻结输入哈希读取此原凭证。它只证明已保留原模型回复，不能证明原候选或运行回执提交。已过期／结束尝试不得借此绕过租约写入 AI 候选；只读查看／复制后由作者在现有表单人工审阅另存，原 AI 凭证仍不改写。缺失或未知凭证不得重发模型请求。

> 白话比喻：保管箱里的小票可以核对旧交易，但不能让已作废银行卡继续刷卡。对应系统：本地凭证恢复证据，不恢复已失效租约的写入权限。

> 速记方法：凭证恢复证据，租约决定写权；未知不重发。

跨机器迁移应备份数据库以及 `data/ai-receipts/chapter-production/`；此目录含未公开正文，按用户数据保护，不能放进公共镜像、打印日志或当静态文件服务。本轮只编写适配器及用例，没有执行真实本地写入，也没有创建实际凭证备份。`tests/chapter-production-receipts.unit.test.cjs` 待主任务在全部编码完成后统一验证；未运行构建、测试、迁移、服务或模型。
