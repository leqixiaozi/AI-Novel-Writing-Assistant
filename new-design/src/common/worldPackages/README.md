# 公共世界固定版本合同

沿用旧版概要、规则、阵营、势力、地点和关系网络六分区，分区归属由作者明确选择，不按标题或文本猜测。公共包是已有正常卡片、类型、表单、关系和字典节点版本的引用集合；书籍事实、状态、正文及认知不进入包。

安装使用完整逐字段映射，各书建立自己的正常卡片及不可变来源映射，不按重名复用对象。缺键与null、空值、0、false分开比较；三方比较的基线固定，不能因读取当前公共版本而移动基线。写入始终携带完整原请求与预览散列。

## 浏览器模块依赖

外部通过 index.ts 消费合同；基础常量、正常安装规格与比较函数由 base.ts 定义。library.ts 和 sync.ts 的运行时依赖直接指向 base.ts，不能反向导入汇总入口。浏览器采用 ESM，循环模块会在变量初始化前触发读取而使整个新设计入口白屏；移动汇总导出的位置不能消除这个循环。仅类型关联使用 type import，不引入运行时依赖。
