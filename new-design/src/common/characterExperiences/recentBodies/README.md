# 最近采用正文人物时间候选合同

本合同独立于小传 `character_experiences_v1`。单批明确选择至多20名实际本书人物、最近五章中1–5份采用正文；完整请求包含范围、指导和预览来源哈希。原快照保存人物真实档案、实际采用正文全文与版本、正文冻结计划以及正式时间／叙述记录，不用当前计划替代。

注册资产 `new_design.character.recent_body_experiences@v1` 负责语义识别。每人至多三个固定候选位置；正文版本、人物归属、实际事件参照和绝对UTF-16原文字位逐项校验。章序、回忆、预叙和发生日期分别表达，未知日期保持未知。

`character_recent_body_candidate_v1` 是独立的候选出处，随正常时间预览、保存和完整原回执保留。编辑器人工字段与正文证据出处分别持久保存，候选不能直接写正式时间或状态。对外从 index.ts 使用类型与校验。

series.ts 仅扩展只读整个范围预检至300人，不放宽单次模型请求的20人合同。预检快照包含全部人物与实际正文，每批哈希从同一完整快照切分人物派生；后续批次仍使用正常单批生成与完整原回执。
