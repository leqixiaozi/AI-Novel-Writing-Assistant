# 人物对话公共合同

`DialogueApi` 是实际页面注入接口；`DialogueSources` 表示截至稳定章的可证来源，`DialoguePromptInput` 仅包括发言者的私有资料、本人认知／状态、公开参与姓名和沙盘成功发言。`DialogueSession`、原回合及动作选择回执分别保留原键、完整输入和哈希。

像拍戏时分发的单人台本：演员可以读自己的内心独白，但不能拿到另一演员的秘密台本。对应代码，本轮认知按 holderCardId 精确过滤；动作引用只能来自这份台本提供的实际 ID。速记：**自己私有，别人公开**。

这些 DTO 不赋予正式写入权；只有显式选择动作才调用原规划 writer 生成独立草稿。`appendDialogueConstraints` 只追加已选择的结构化约束，拒绝新重复/no-op 和超限，不删除或修整原规划内容。未知调用不等于零用量、不等于失败未发送；费用价格缺失不推测。
