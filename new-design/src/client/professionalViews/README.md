# 专业图形视图

`ProfessionalViewsPage({bookId,api:ProfessionalViewsApi})`，只读 API `getProfessionalViewsWorkspace(bookId)`。根页面负责挂载 `/new-design/books/:bookId/professional-views` 与 `professionalViewsRouter()`；本模块不持有中央路由或第二份资料保存方法。

> 白话比喻：把同一本通讯录画成连线图，姓名和联系方式仍在原通讯录。对应到系统：节点来自原资料版本，边来自原关系版本，编辑调用同一 `BusinessFormWorkspace`。

> 速记方法：图里选、原表填、来源查。图的位置不是关系或故事事实。

## 四个真实视角

- 人物关系图：真实人物与本书关系实例；有向／双向不同，旧版本标明需核对。画布最多80个匹配人物，完整已读取目录保留；关系不从介绍文字推断。连线详情导航到已有本书关系维护来源人物及正式规格，没有新增关系写入链，也不声称精确选中关系实例。
- 人物成长：原 `state_changes` 按实际故事顺序与 sequence 排列，无故事顺序放末尾。当前状态、历史流水和所知分别显示；已切版正文或无效规格保留历史，不假称当前成长。真实来源按钮回原章节确认会话。
- 世界时间：原正式 `story_event_timings`、事件关系与跨章 occurrence；没有确认的提案不冒充正式安排。不从记录日期猜故事时间。编辑回现全书编排时间编辑器，节点编辑原事件表单。
- 地点地图：作者明确选已有正式数字字段作横纵坐标，保存精确字段版本引用；只读这些原档案值。没有坐标不造地理，没有底图／地理编码服务。字段改版不会默默替换；文字、空值、不合规格与缺版本对象不在图里放猜测点。图仅作品坐标图，不声明经纬度语义。

## 保存、失败与范围

布局、视图切换、搜索、选中与坐标字段绑定只存本机 `sessionStorage`、按书隔离，**不包含资料事实副本，不跨设备同步**。存储坏记录不按空白覆盖，存储失败保留旧记录并暂停改写视图偏好，提供运行维护和原资料入口。跨设备事实仍是原数据库与后续备份恢复，不把本机偏好算正式坐标规格。

原编辑器保持正常原请求凭证、AI候选明确采用、字典树与字段规格；未知写入不能切换节点／视角，未保存填写先保留。读失败不卸载原表单、清原请求或重发模型。book scope 用组件 key 隔离，异步读序号与卸载 guard 防迟到覆盖。来源按钮另开页不卸载填写。

> 白话比喻：同一张桌上的几本账本各自有结账时间，不代表整桌已经统一封账。对应到系统：组合视图读取原模块各自事务；保存仍由原正本核对最新版本，不承诺组合页面是跨模块冻结快照。

> 速记方法：读取可不同步，写入必须核对原版本。

无新增数据库迁移，AGE只可作为原关系的可重建投影，不是正本，也不是本页运行前提。遵循 frontend-design 的功能主义与现有 HSL 主题、移动单列、44px按钮和16px控件。
