# 故事设定与故事规划

本模块提供 story-setting 与 planning 两个书内工作区。复用标准业务表单、规划版本及其原 API，不创建第二套资料或事实账本。旧 setting、world、characters、cards、views 深链接继续有效。

设定通过 tab、selected、detail、relation 保存当前位置。规划通过 tab、scope、selected、plan、display、detail 保存范围及位置；旧 plan hash 可读取。returnTo 只接受同一本书的 planning 地址。范围按规划父子关系取后代，缺失标识与重复来源参数阻止误选。

规划版本 content 的 eventSchedule 保存事件发生次序及作者时间说明，relationshipPlans 保存人物关系意图；两者均为计划，不修改结算事实。其他自定义 content、资料身份及版本引用沿原保存合同保留。

离开脏表单提供保存、放弃、取消。原提交未知时保留完整原请求并阻止重复提交；只读刷新不能证明请求未写入。设定对象初始值与章内历史、当前状态、快照分开。

BatchAiPanel 使用 story_workspace_ai_v1 原请求及冻结来源准备整组设定／范围规划候选。设定只补空白；规划已有字段默认不勾选，事件时间和关系意图可作为结构化计划建议。候选逐项载入原编辑器，明确采用勾选字段后正常保存；规划还须单独采用版本，不写正文或结算事实。

原请求保留在 sessionStorage，刷新只读取原批次；结果未知时不能重发，明确结束运行占用保留未知结果及用量。运行记录链接携带 batch 标识返回原候选。载入前检查来源指纹／修订／采用依据；迟到读取受序号与书籍范围保护。

规划 pending 凭证包含实际发送的完整创建／修订输入，按原 planning_operation_events 哈希核对；初始值请求 UUID 指向原不可变初始值版本，核对规范输入哈希。没有完整原凭证的旧未知请求保持待核对，不用当前读到的相似资料补造成功。

验证使用 noEmit 与 story-workspace、planning-ai-interaction、book-navigation 单元检查；真实模型及采用写入不能用静态测试代替。

## 旧版填写页的展示适配

`referenceLayout/` 拥有人物目录、选中摘要及只读业务详情。人物恢复总览、档案、外显、资源、时间线、关系、动态、智能层八页签，并保留新版独立初始状态。世界按旧本书手册的总览、规则张力、生成约束、使用范围、同步资产组织查看，左侧手册菜单宽 220px，同时保留标准档案编辑和初始状态。

字段与数据仍由已发布的本书规格、作用域扩展及原业务表单拥有。`common/formPresentation` 仅负责展示：主配角分区使用已安装 `story_role` 枚举，不猜测名字或自由文本；字典树定位无法按枚举识别时进入未指定定位。档案与外显使用已发布字段分组分区，自定义组留在档案。DynamicForm 不裁剪字段或值，AI 收到完整字段与当前填写；任何分组的校验错误都显示对应分组。基础字段两列、纯长文本组三列，窄屏减少列数。

同一人物的档案与外显共用同一个挂载编辑器与完整草稿，切换仅改变展示。切到对象、其他详情或离开书籍仍走原保存/放弃/取消保护，原未知提交仍锁定。只读专业投影核对书籍、模式、焦点对象，不用另一人物替代；刷新受卸载保护，不写事实。人物专业图形视图携带已校验 `selected` 和 `view`，模拟携带 `participant`，不会覆盖已恢复会话或未知原请求。

| 旧能力 | 本轮新版对应与限制 |
| --- | --- |
| 人物档案、外显 | 原标准表单按分组展示；未知扩展保留。默认规格含外貌、语言习惯、动作、性格、长期目标等；旧性别、背景、成长、当前处境/目标没有默认一一对应，不能把长期目标改称当前目标，也不自动新增到现有书籍。 |
| 资源 | 已安装表单的真实关联及引用版本，只在有规格时提供原表单维护；并非持有资源账本，没有旧“回填最近章节”操作。当前人物没有关联规格时明确显示不可用。 |
| 时间线 | 当前人物的叙述安排和正文锚点，链接原规划、确切章节及世界时间视图；不冒充自动时间线同步。 |
| 关系 | 保留原关系草稿/发布/初始值合同，链接精确人物关系图。 |
| 动态、智能层 | 读取正式当前状态、关系状态与人物认知，沿真实来源审阅；可进入当前人物成长视图/模拟，未调用模型。 |
| 世界规则与生成约束 | 展示本书实际世界规则、时间规则、能力规则与所选档案。档案文字不等于已生效生成约束，正式装配仍归本书上下文配置。 |
| 使用范围 | 表单关联及其局部信息；尚未等价复刻旧主线舞台、核心势力和地点使用约束。缺规格不显示无效维护按钮。 |
| 同步资产 | 可查看字段来源、地点势力、道具及本书专业维护；公共世界双向分段同步没有新版对应合同，直接说明不可用。 |

补齐缺失默认字段、人物/世界关联表单、旧专门 AI 操作、资源回填及公共世界同步，需要先明确语义、版本安装与来源快照方案并确认；本轮不迁移、seed、覆盖用户规格或写测试到用户库。旧角色库导入和准备向导也未宣称已等价。样例书在线读取、页签及未保存值保留可验证布局，不能据此声明真实保存、AI 或全部世界功能通过。
