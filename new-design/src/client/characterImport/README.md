# 公共角色导入页面

公共资源目录及创作资源导航进入本模块。先选角色、不可变版本和目标书籍，再逐来源字段选择本书真实字段，检查映射值并填写其余必填信息。预览后明确创建书内独立人物，最终入口精确返回book＋card＋type。没有名称合并、自动公开、旧库迁移、正式状态／认知／持有关系复制。

草稿独立持久，0／false与不同源／目标键保留。来源或书籍切换、页内离开使用原workspace guard，刷新用beforeunload；保存待核对或坏存储时不能切换。原导入请求持久且跨刷新恢复完整书籍、版本、映射、额外手填与预览哈希。接受回执逐项核对完整输入、创建身份与原路由，先保存结果与填写再清理原键；未知只读核对，无自动再次导入。新来源读取代次隔离迟到响应，不覆盖映射。原字段和本书值两列平铺，较小屏幕一列；此阶段未以真实用户页面交互验收。
