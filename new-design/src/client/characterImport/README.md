# 公共角色导入页面

公共资源目录及创作资源导航进入本模块。先选角色、不可变版本和目标书籍，再逐来源字段选择本书真实字段，检查映射值并填写其余必填信息。预览后明确创建书内独立人物，最终入口精确返回book＋card＋type。没有名称合并、自动公开、旧库迁移、正式状态／认知／持有关系复制。

草稿独立持久，0／false与不同源／目标键保留。来源或书籍切换、页内离开使用原workspace guard，刷新用beforeunload；保存待核对或坏存储时不能切换。原导入请求持久且跨刷新恢复完整书籍、版本、映射、额外手填与预览哈希。接受回执逐项核对完整输入、创建身份与原路由，先保存结果与填写再清理原键；未知只读核对，无自动再次导入。新来源读取代次隔离迟到响应，不覆盖映射。原字段和本书值两列平铺，较小屏幕一列；此阶段未以真实用户页面交互验收。

## 公共样本管理入口

`/new-design/resources/characters/library` 复用原专业资源工作台及原 Card／CardVersion／不可变回执，按 character 分类限制操作；资源树、导航和导入页均有入口。支持创建、编辑、收藏、归档和按确切原规格查看历史。编辑及创建规格在打开时冻结，刷新目录不改提交凭证；明确核对最新值／规格后可保留填写改用新版，未知字段不静默删除。此编辑区只修改发布类型字段，原局部补充值和表单来源按确切原版本保留，历史仍完整可读。

管理需要手动096扩展及显式 operational 启用，缺失／关闭／原回执保护触发器未启用时禁止新管理操作，但历史和原回执只读保持。未安装作者库。角色不走策略组合安装，也不借通用稿件诊断冒充对话试用；固定版本公共图片与专属多轮试聊由 `/new-design/resources/characters/workshop` 承接，使用另需显式启用的手动097合同；不借书内沙盘或通用稿件诊断替代。图片支持1–4张顺序生成及主图／归档，未知保留原键，原回复可续存；完整旧版中英优化和原链选择仍未实现。新用例只编写，浏览器与保存行为待统一验证。
