# 人物模拟来源页

实际页面 default `CharacterDialoguePage({bookId,api:DialogueApi})`；中央挂载 `/new-design/books/:bookId/character-dialogue`，稳定注入原新设计 API。复用主题令牌和现有中文表单，不添加作者任务中心变更按钮。

流程：选择稳定截至章与参与资料 → 加载真实当时来源 → 保存沙盘范围 → 明确生成一人一轮 → 查看原候选 → 勾选动作 → 选原规划版本 → 明确追加草稿约束。模拟不是事实；就像彩排不会把剧情自动写进出版稿，只有作者点选才存一个规划草稿。速记：**模拟可看，采用另点**。

`session`、`round` URL 只允许单个 UUID；指定来源不存在/不匹配则锁写，不 fallback。保留人工输入和未保存动作勾选；切换需明确确认。书籍代次和忙锁防异步迟到覆盖、双写。

原 pending 以完整作用域/输入 SHA-256 保存浏览器技术凭证。未知只 GET 原键；GET 阴性不清键。纯 DB 会话/动作保存可明确按同键完整 payload 核对并完成原操作，不模型；恢复旧未知即使本次回滚仍保留原键。只有首次全新请求可信 not_written 可解锁并保留输入。已保存回复完成/结束按钮只操作原回合；原 lease 超期且无回复才可结束未知，不调用模型。

旧缺身份或坏存储保持阻塞；维护链接只导航，不自动修复凭证。首次领取响应丢失且无可读原回合/租约的极端状态仍不能用 GET 阴性解锁。没有全站恢复已通过的声明；页面尚未执行浏览器和运行验证。
