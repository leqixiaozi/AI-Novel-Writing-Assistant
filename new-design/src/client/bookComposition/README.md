# 全书编排的正本边界

全书台读取原故事、卷、章节、场景规划，以及原章节工作台；事件仍是规划引用，不增加事件规划层。正文候选、比较、采用与结算必须消费原章节组件，不能在此模块复制写入或模型执行。

> 白话比喻：全书台像书桌上的目录索引，正文还在同一本稿本里。对应到系统：目录来自 `planning_objects`，编辑来源是既有正文版本；界面切换不复制正文或建立另一套章节。

> 速记方法：目录读规划，正文用原台，采用走确认。存储的本地草稿不是已保存候选，也不是采用正文。

`CompositionBodyDraft` 按本书和真实章节资料保存原正文、基线、来源版本、原请求标识。读取范围不符的草稿拒绝恢复；刷新未知回执只允许查询原请求，不能因为未找到而再次提交。异步章节读取使用序号，迟到结果不能覆盖另一章节的手填稿。

全书页面实际挂载原章节工作台，目录按原故事→卷→章→场景读取。排序先冻结全书规划及正文档案修订，预览全部章节顺序；作者明确确认后，同一事务更新原目录和合法全书连续章序。临时位置避免唯一约束碰撞，归档档案占位冲突则拒绝暗改。065 仅保存原命令的不可变回执，不复制规划或正文。

书籍主导航由 `bookNavigation` 按创作概览、故事设定、故事创作、完本与导出四个模块分组，左侧功能树只导航到原来源，可向左收起并保留右侧编辑器。卷章场景目录是具体对象树，不用功能菜单替代；消费公共 `TreeNavigation` 与 `flatNavigation`，保留原规划 ID、父关系、同级顺序及未采用状态提示。搜索显示匹配项及其祖先；折叠不切换正文，名称选择继续执行原草稿保留与请求锁定检查。失联父项或循环关系只进行防死循环展示，不自动改写规划；资料维护页面仍是原修复来源。

故事时间、因果/并发关系与跨章叙述位置采用原故事时间领域。时间或关系先保存提案，再单独审核；跨章位置明确新增为同一事件的另一引用，不覆盖第一次出现。预览显示原值、目标值和实际已保存的事件引用规划范围，正文、对象及资料关系状态不在此处自动改变。已有正式时间通过明确替换来源修订，不能新增后偷偷覆盖。

> 白话比喻：同一场婚礼可以在第一章现场讲、第五章回忆讲，邀请函日期仍是同一个。对应到系统：事件资料不复制；叙述位置可有多处，故事时间和因果关系各自经正式提案确认。

> 速记方法：章序管阅读，时间管发生，因果管为什么；提案先保存、审核再生效。

068 只记录原领域命令的技术回执，原函数接受同一个事务客户端；修改与回执一起提交。确认回滚才标“未写入”，提交应答不明保持未知。读取空回执不能证明未执行，未知禁止重复写入；成功回执先保留，后续刷新失败不改为保存失败。草稿按本书及来源隔离并冻结修订，只读刷新不默默重基准，须作者明确重新准备。

必要迁移和原事务修改已获主代理批准。单元/负面用例已编写，尚未执行测试、类型检查、构建、运行 GET 或迁移，不宣称验证通过。

最终静态收口：目录读取的成功与失败都校验请求序号；章节读取同时校验实例原书籍与当前书籍。组件被跨书复用时锁定提交，保留原书稿件与原请求，只提供原书来源返回。章节、排序与事件恢复标记存在但不完整，或网站存储读取／保留失败时，不当作空白新稿、不覆盖原凭证；先在运行维护核对，再回原来源只读查询。

原章节 AI 请求仍由原受控单章入口执行，没有另起保存器。只有原记录明确说明已保存回复时，才提供“恢复原已保存回复到候选/完成原生成回执”；只有实际租期过期且没有已保存回复时，才可明确结束过期原未知领取。恢复中按原请求 ID、原不透明请求标识、本书、本章持久保留；读取生成中不视为恢复完成。成功须候选已入库并终止回执，或者原领取已取消。读取失败保留已确认成功，不重调用模型，不自动采用候选。

专业来源使用本书精确 `planning?plan=<原规划ID>`，兼容原 `#plan-<ID>`。只匹配本书实际对象；缺失或格式错误显示来源问题，不转到首项、不允许以空来源保存。手填和迟到读取有保护，切换前要求明确保存原候选。

工作台顶端提供章节正文、故事时间线、线索伏笔、角色组织和人物关系的显式视图导航。章节与时间线保持原编辑器挂载，线索、角色和关系导航到已挂载的本书多维正本页；不另做影子编辑器。正文搜索、选中规划与冻结人工稿件保留，原请求待核对时阻止离开。故事来源补读的成功、失败、结束状态均校验请求序号与书籍范围，迟到读取不会清除新页错误。

原回复窗口只读查看精确原请求的完整正文，并可明确复制。数据库原回复和本机文件凭证分别说明；本机凭证不是数据库入库证明。恢复中断时按原请求只读核对；已确认尚未领取可明确取消，数据库回复已存但无法导入可保留回复并结束导入。所有动作保持同一正文来源，不调用第二次模型，也不自动采用。
