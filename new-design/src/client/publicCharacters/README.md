# 公共角色固定版本试用页

入口 `/new-design/resources/characters/workshop?resource=<UUID>&version=<UUID>`，由样本管理及确切历史版本打开。`api.ts` 消费共用 PublicCharactersApi；`draft.ts` 校验完整草稿、原批次和回执；页面负责固定来源、试聊链、图片填写、原请求核对及主图／归档确认。

本地原记录完整保留角色／版本、人工填写、成功会话链及批次每个独立原键。发送前先持久并回读完整输入及 dispatched 状态；持有浏览器同名独占锁直到本次调用处理结束。另页修改存储、坏帧或回读失败锁定写入，不覆盖原记录。目录刷新不改变来源和人工填写，迟到读取用代次与固定来源隔离；未完成原请求优先于另一个深链来源。

对话每轮明确发送，只引用同一固定档案和完整成功历史，最多31轮；观察和缺失信息只是审阅资料。图片明确选择专属连接和尺寸，1–4张逐张执行，每张都有原键。未知停住，不换键重发；只读核对可确认原结果并推进本地批次位置，但不会发送剩余图片，剩余调用须明确继续。收到完整匹配回执先持久结果，再清理原键。

保存已有原回复、结束过期未知领取是原来源页的显式操作，不调用模型。图片主图和归档要求确切最新事件，归档有后果确认；旧图片、原文件和回执可读。导入书内角色仍走原字段映射预览，不自动导入或修改正式事实。手动097缺失／关闭时禁止新试用，保留已有档案和结果只读。

双端 noEmit 已通过；本地恢复、模型协议、真实图片、HTTP、隔离PG和页面交互仍待统一功能验证。尚未在作者环境安装097、重新加载服务或调用真实模型；中英图片优化与原链发送选择仍缺受控合同。
