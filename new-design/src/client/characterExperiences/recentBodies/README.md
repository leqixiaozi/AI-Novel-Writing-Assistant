# 最近正文时间同步源页

index.tsx 提供人物／采用正文范围、完整原文预览、明确确认、结构化候选检查及载入正常时间编辑器。原请求响应未知时锁定范围；刷新只恢复完整原请求，明确只读核对读取已保存批次。选择实际事件并载入后，正常时间编辑器保存提案，再单独审核。

recovery.ts 保存完整原请求和逐请求结果，使用浏览器排他锁及完整输入比较防止旧页面覆盖新凭证；无锁、坏凭证、存储失败均停止新发送。异步响应与等待锁后的操作须核对当前挂载范围；离页不得迟到发送结束未知请求。api.ts 只提供此子域类型化调用。

人物时间页只有一份正常时间编辑器。其脏草稿或未知提交禁用新的正文同步，正文同步未知时同样保护正常编辑器。正文证据保留原链接与绝对UTF-16位置，未知日期不按章序补造。

本阶段为单批至多20人；全部人物分批仍待接通，不把小传同步按钮当作正文同步。隔离页面验证不代表5301已加载或用户验收。
