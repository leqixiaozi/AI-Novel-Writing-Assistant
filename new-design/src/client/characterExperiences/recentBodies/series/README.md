# 正文人物完整范围分批

完整范围至多300人，先只读取得同一实际来源快照及每20人的来源哈希；作者核对全文和全部人物后才创建计划。controller.ts 预分配每批完整原键、正文范围、指导及哈希，发送前持久保存 pending；确定结果持久保存后可顺序处理后续批次。

模型、HTTP或结果存储未知停止后续。刷新不发送；只读核对只保存原结果，ready 需另一项明确继续。后续实际人物／正文／正式时间来源变化由正常生成入口在模型调用前拒绝，该轮停止，不用当前新值替代。显式结束未知或剩余部分保留整个来源、原请求及已有结果。

单批与分批共享当前书籍人物的浏览器排他锁。每次操作核对完整已存计划，旧页发现新进度只同步显示，不覆盖／继续；单批原请求待核对时禁止分批，ready／pending分批同样禁止新单批。锁不可用、坏凭证、跨书、保存失败均停止发送。卸载与重挂载有不同代次，旧代次的锁等待或迟到回复不能推进后续。

正文出处、提案事务和独立审核仍由正常时间模块拥有。已存批次候选的检查先读服务器完整原结果，不把浏览器缓存当采用授权。公开使用 index.ts；小传分批合同保持独立。
