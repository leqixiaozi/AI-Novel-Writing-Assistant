# 世界库同步页面

本模块属于故事设定的“同步与资产”，沿用旧版同步管理、六分区选择、来源与世界库、最近同步的紧凑结构。字段填写复用正常动态表单和实际字典树；公共来源与本书字段必须显式映射。

`index.tsx` 是外部唯一页面入口；`api.ts` 由客户端 API 门面装配；`Import.tsx` 负责完整独立副本预览与导入。`command.ts` 在浏览器锁内保存完整原请求后发送，结果不确定时只读核对。确认回执先保存完整结果，再清理原凭证。刷新、另一个标签页和离开页面不能触发自动重写。

同步写入均需先预览再确认。推送只准备不可变候选，公开发布是另一项明确操作；其他书籍继续保留独立版本。能力未启用时保留书内编辑入口，不提供无效同步操作。

完整原请求和已确认结果必须写入后回读一致，才可发送或清理凭证。导入、公开与同步草稿坏帧或存储失败保留原记录并禁止新操作；明确放弃只能清理未保存填写，未知原请求仍须只读核对。跨书／世界切换的迟到回复不能应用到新范围或清掉原来源凭证，原来源刷新迟到也不能清掉新范围选择。相关恢复用例已编写，功能仍待统一验证。
