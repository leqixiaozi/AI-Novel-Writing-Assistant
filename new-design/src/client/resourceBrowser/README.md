# 多层创作资源浏览器

资源主页采用领域 → 类型 → 原资源的多层目录，右侧呈现具体内容，避免查看一项题材策略也必须跳转页面。展开和搜索只是本机视图状态，不新增业务数据或替代原分类。

> 🏠 白话比喻：左边是文件柜目录，右边预览原文件；要修订或装入书里，就打开这份文件的工作台。对应到系统：树节点保留原资源 ID，预览不写入；专业工作台处理保存与安装。
> 🧠 速记方法：目录负责找，预览负责看，工作台负责改；候选和业务正本不因展示方式改变。

## 边界

- `catalog.ts`：纯目录构造、层级查找、搜索保留祖先路径。
- `ResourceCatalogTree.tsx`：折叠和选择，搜索不重置右侧填写。
- `ResourceCardDetail.tsx`：按精确 `typeVersionId` 只读预览正式字段；四类策略以原资源 ID 直达资源工作台，分类新建入口带类型参数进入同一页，提示词和市场信号回原编辑器。总览不再另设策略保存或安装入口。
- 书籍仅提供精确所属书入口，不将本书人物、世界、事实纳入公共策略保存路径。
- 最近更新与整理资源纳入同一树。整理沿用原标签／分组／智能视图；策略空间使用原 `60000000-0000-4000-8000-000000000001`，不误用系统空间。
- 字典、标签展开到真实原节点，右侧查看名称与说明；修改结构、顺序和引用继续使用原树编辑器。

## 失败与填写保护

总览只读预览，可自由切换与刷新。专业工作台负责未保存填写保护、原请求核对、资源修订和组合安装。预览读取时核对资源身份及精确内容规格，失败不改选其他来源。目录独立读取，各失败项标明所属领域并可重新读取；其他成功领域仍可用。

这里不是完整任务恢复系统。原整理面板的分类编辑与请求恢复规则仍归其模块所有；本浏览器未替换其合同或新增持久凭证。专业工作台原路径与资源深链保留；新建、归档、版本历史、提示词分类及字典顺序的专用入口也保留。
