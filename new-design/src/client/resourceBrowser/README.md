# 多层创作资源浏览器

资源主页采用领域 → 类型 → 原资源的多层目录，右侧呈现具体内容，避免查看一项题材策略也必须跳转页面。展开和搜索只是本机视图状态，不新增业务数据或替代原分类。

> 🏠 白话比喻：左边是文件柜目录，右边打开原文件，不能为了换目录再复印一份文件。对应到系统：树节点保留原资源 ID，策略保存使用原资料接口，安装仍生成对应书籍独立快照。
> 🧠 速记方法：树负责找，表单负责改，原库负责存；候选和业务正本不因展示方式改变。

## 边界

- `catalog.ts`：纯目录构造、层级查找、搜索保留祖先路径。
- `ResourceCatalogTree.tsx`：折叠和选择，搜索不重置右侧填写。
- `ResourceCardDetail.tsx`：读取精确 `typeVersionId` 的正式字段；四类策略直接编辑，提示词和市场信号只预览，分类、配方、引用和研究操作返回原编辑器，不能绕过专属保存合同。
- 书籍仅提供精确所属书入口，不将本书人物、世界、事实纳入公共策略保存路径。
- 最近更新与整理资源纳入同一树。整理沿用原标签／分组／智能视图；策略空间使用原 `60000000-0000-4000-8000-000000000001`，不误用系统空间。
- 字典、标签展开到真实原节点，右侧查看名称与说明；修改结构、顺序和引用继续使用原树编辑器。

## 失败与填写保护

策略编辑时阻止切换、刷新和离页误丢稿。保存失败或结果未知不自动重发：读取服务器内容，明确核对后保留填写使用当前修订继续。来源、状态或规格变化时不换成其他来源。目录独立读取，各失败项标明所属领域并可重新读取；其他成功领域仍可用。

这里不是完整任务恢复系统。原整理面板的分类编辑与请求恢复规则仍归其模块所有；本浏览器未替换其合同或新增持久凭证。新建、归档、版本历史、提示词分类及字典顺序的专用入口保留。

当前编码及静态 review 完成。新增六项用例仅已编写，未执行本批统一类型／构建／测试或浏览器验证。没有新 SQL、迁移、模型请求或真实数据库操作。
