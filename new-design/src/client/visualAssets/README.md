# 视觉资产来源页

默认导出 `VisualAssetsPage({bookId,api})`，路径 `/new-design/books/:bookId/visual-assets`。左侧封面／插图折叠树，右侧中文名称、说明、本地文件、原版本、影响预览与绑定表单；主题继续消费既有颜色变量，普通字重与响应式左右结构，不另造视觉主题。

严格 `asset/version` UUID 参数，重复、空值、只有版本或未加载的原版本明确标失败，不选择其他图片或当前版本代替。图片只用受控服务二进制 URL，不显示任意 locator 或外部链接；读取失败保持原版本，提供只读重新读取同一原图按钮。

人工填写、原本地 File、归档原因和绑定说明不被目录刷新覆盖。切图片／版本需要明确放弃未保存填写；切书保留原来源并锁住新书写入。写入忙／未知锁定原位置，浏览器离开有保留提醒。完整原输入和 key 尽量保留本会话；10 MiB 图片超浏览器存储容量时只保存安全原身份，当前内存仍保原图，重开后 GET-only。损坏标记不能默默丢掉制造新请求。

> 白话比喻：打开相册不会撕掉桌上未写完的照片备注。对应系统：刷新只读目录，草稿留在编辑表单；切换要先确认放弃草稿。

> 速记方法：刷新不换稿，版本不替代，原键先核对，采用需确认。

失败展示中文步骤、需要修正的字段位置、保留结果及原来源按钮。GET 核对失败不清原待核对键；纯数据库“完成原操作”先 GET 正向回执，否则同一完整原输入和 key 提交，只有真实写入的事务证明可解锁为未写入，不能拿 GET 的 not_written 推断旧写入。只有 key 没 payload 不允许重选图片冒充原请求。上传、说明只形成候选；明确采用／归档先真实影响预览，绑定固定正式内容和图片精确版本，不改正文。

真实图像生成缺执行合同，页面明确能力尚未注册而非假成功，也不借文本模型或旧作者路线。当前只维护已有真实本地图片。
