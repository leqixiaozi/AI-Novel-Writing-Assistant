# 组合预览的资料取舍

组合编辑沿原组件配方和参考政策保存，预览显示精确组件／来源、真实冻结消息和路线。预览中的纳入／排除按钮只修改当前组合草稿，必须再次保存并生成新预览；旧冻结请求和原回执保留，不能把新编辑套入旧请求或自动采用小说事实。

组件 enabled 和来源列表取舍由原草稿 change 路径使旧预览失效；父页面提供实际回调，无新引用政策／正本。正式和参考角色沿既有 E/F 政策，来源版本、跨书范围及原 schema 仍由原准备门面严格核对。

客户端编译、组合合同／UI 单元及精确保存／预览／单次账本的真实 PG 通过。新增按钮和实际页面取舍尚无浏览器证据，保留待验；真实模型质量与作者启用未执行。
