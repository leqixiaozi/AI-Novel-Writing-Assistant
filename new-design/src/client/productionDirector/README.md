> 白话比喻：左侧选一张工单，右侧核对它的每一步；故障灯旁直接告诉你回哪一步处理。对应到系统：真实范围选择、中文错误阶段、保留结果、原请求只读核对和明确动作放在同一来源上下文。

> 速记方法：选范围→保存范围→明确开始；有故障先看原回执，再按来源按钮处理。

候选计数不是采用／稳定正文进度。已有原回复才出现免重复模型的入库恢复；继续范围会说明后续章可能产生新用量。每章链接返回其真实章节候选、采用与结算，以及精确规划。运行记录只负责查看与跳来源。
