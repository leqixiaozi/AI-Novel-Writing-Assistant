# 作品分类和体验偏好

保存目标是本书唯一原 `project_rule` 作品约定卡片：publication_status、writing_mode、writing_platform_preference、creation_experience。复用原类型字段，缺少时只增加原卡片局部字段及不可变规格／scope adoption；所有原值和局部值进入正常作者保存的原卡片版本与回执，无新正本、表或书籍猜测字段。

草稿／已发布仅为作者维护的分类，不执行外部发布；原创／续写与引用选择独立；平台沿用五个实际旧语义，历史缺少原值保持未设置。模式为 simple／professional，不按页面访问猜用户偏好。缺作品约定或存在多份时提示回原来源处理，不自动创建或挑选。

完整本地帧、原键、期望修订、浏览器锁及正常原回执保护写入和离开；未知先只读核对，不根据空查询自动重发。编译、分类合同单元及实际保存／并发同回执／书架正式分类 PG 通过。桌面四字段分栏、窄屏响应、说明收进帮助，实际页面保存及作者验收仍待。
