# 本书图片生成中文表单

入口复用本书图片页，`ImageGenerationPanel` 接受 `{bookId, api:ImageGenerationApi, disabled?, onSaved?}`；专属连接通过 `ImageConnectionPanel` 显式配置，原模型凭据目录只返回脱敏引用。不会预选第一个模型、默认文字模型或付费服务。

> 白话比喻：图书编辑先收到样张；缺主封面时第一张可用封面补空缺，其他样张仍可审阅。对应系统：原图片生成先保存候选，缺主封面时由原视觉事务完成采用和准确绑定；插图保留候选边界。

> 速记方法：生成留样张，采用定封面，绑定定页面。

画面填写和原请求在本机 sessionStorage 按原书籍保存；冻结原输入使用 UUID 原键及完整输入哈希核对。恶意/损坏/跨书恢复记录锁写，不把存在的坏记录当空草稿覆盖。恢复不信本地声称的回滚/读取成功，刷新后只读核对；没有回执不证明没有调用。

专属配置未保存填写也保留。坏原凭证或浏览器容量故障持续锁写，保留旧记录。已确认未写入且原只读核对完成，才显示明确“保留设置/画面并重新准备”；未知不显示这个入口。成功连接的正向原版本与完整哈希通过核对后才清 pending，目录读取失败保留已保存版本。

生成失败区展示中文阶段、字段位置、保留结果及模型设置/运行维护入口；导航只打开来源，不重发请求。收到原回复后显示“继续保存原图片回复”，只处理同一原请求，禁止再次模型调用。过期未知的结束动作要求明确确认，不将未知用量说成零。

共享 ImagePreparationPanel 读取完整原书籍／卡片／局部字段／采用故事总纲资料，作者可编辑完整草稿并明确优化为中文／英文，选择原文／优化结果送回原图片表单。新优化合同与图片原合同独立，发送附确切优化结果、选择和来源哈希；未确认优化、坏帧或忙态阻止原图片发送及关闭。原批次真实准备／调用／待存结果分开显示，不制造后台已排队凭证。

所有普通字段中文，原请求／哈希和完整来源折叠只读。双端编译及原协议／批次／回执、优化选择单元通过；实际优化／首成功／替补 PG 因公共夹具前置保护未进入，视觉／浏览器验收待验。
