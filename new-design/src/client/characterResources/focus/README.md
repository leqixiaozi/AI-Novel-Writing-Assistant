# 原资源页显示建议

公共入口为`useResourceFocus`、`ResourceFocusPanel`和`resourceFocusView`；`api`是主客户端API组合的显式传输适配器。人物资源页始终挂载恢复控制器，未知请求自动显示只读核对入口并锁定新范围。按原记录链接重开只读载入完整原结果，不发模型或结束动作。缓存结果必须重新读取完整原请求，核验真实原回执和当前完整来源，才能恢复作者曾采用的显示选择；缓存不充当服务端原结果。

建议必须先展示完整原人物和资源范围，再明确准备。采用只是显示偏好：实际sourceHash和完整来源帧都要一致，主角10／长期6／临时5条；临时角色按AI结构化重要性过滤普通资源，unknown仍可核对，全部原资源可展开。数量0、false、状态与认知由原账本展示；筛选不修改候选范围，最近章回填仍使用完整明确选中的资源，而不是显示子集。

迟到读取受组件生命周期和epoch保护。拥有者`recovery`在同书人物浏览器锁内核对完整原请求帧，再准备、读取或结束；旧页面不能清除另一请求的凭证。原回执或偏好写入失败保持原请求；来源已变或无法核对时不隐藏原资源，不根据最新列表猜模型是否执行。原占用只有源页明确确认结束，服务器核验执行锁和完整原输入；结束不删除来源、不声称用量已知、不自动再次生成。结束响应未知保留原输入，先只读核对完整原结果，不自动重发或生成。逐请求的完整结果及显示选择按原键保留，读取同原结果不重置已明确采用的偏好，旧原结果不能覆盖更新的缓存记录。运行记录保持只读。

“核对原确认的转交与淡出”明确准备独立v2范围，展示完整原确认和原正文证据，再使用专属受管AI判断历史语义。实际来源已核验和作者已采用分别处理，未采用仍可展开全部原历史；临时角色优先保留有证据的已转交资源，长期角色收起有证据的淡出资源。来源变化或读取失败仍保留原结果和全部历史，当前持有保持待核对，不将旧建议用于过滤。重新核验和采用后同步刷新父页实际只读账本，不因旧帧阻止新建议显示。transfer_plan、false、归档和缺少当前关系均不能代替已转交语义。

最终37项检查及实际隔离浏览器验证覆盖完整原结果恢复、临时／长期显示、全部展开、刷新采用与来源变化。在线安装／加载／真实模型与用户验收不由隔离检查代替；最近采用正文时间同步仍待实现。
