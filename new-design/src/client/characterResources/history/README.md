# 源页历史核对

只在原人物资源页明确读取完整所选维度，按原关系聚合章节确认；不调用AI、准备候选或产生正式状态。原变化与当前持有分别展示，失效记录和证据保留。所有迟到读取受人物、完整维度和生命周期保护，SQL错误不展示为空历史。超界明确不完整。展开原记录仅导航确切正文和原确认，运行记录不新增动作。

ResourceHistoryItemView在原资源网格紧凑展示原关联、当前持有是否已确认、各章原变化与确切正文；同名资源不合并。转交／淡出建议来自focus独立v2结构化AI合同，仅在实际来源核验且作者明确采用后显示。未采用或来源变化保留全部原历史，不作当前持有结论。实际只读历史页面及转交／淡出显示流程已在独立隔离服务验证，未在作者服务加载或使用真实模型。
