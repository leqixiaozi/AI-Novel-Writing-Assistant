# 专业资源来源页

默认导出 `ProfessionalResourcesPage`，注入共用 DTO 的 `ProfessionalResourcesApi`（目录／命令／原键回执）与 `ProfessionalTrialApi`（全部消费原组合 DTO）。不修改作者模型默认值，不新建试运行账本。

左侧使用 `../tree` 公共门面导出的 `TreeNavigation`，与创作资源总览共用目录行、展开箭头、缩进与选中样式；右侧编辑原资源。类型是目录分支，点击类型名称只展开／收起，不创建草稿，不修改当前资源。分类加号才明确进入该类型的新建表单；未读取到真实已发布类型时禁用新建。叶节点携带原资源对象及稳定 ID，经既有 `choose` 处理选择，不能由树组件另存一份业务选择状态。

搜索覆盖五种资源类型，按中文类型名称或实际资源名称查找；收藏／归档筛选同时作用于所有分支，计数是筛选后实际叶节点数。搜索保留父分类，不切换右侧、不清空隐藏资源的当前填写。归档叶显示只读状态；原修订号与收藏状态保留在节点解释中，收藏有图标标识。公共组件仅负责显示和展开；保存、回执、采用、安装与试验仍由来源页负责。

全部使用已发布动态字段及既有主题变量；最多四个标题按读者承诺／受众／误导风险并排比较，收藏不等于采用。书名采用、资源清理归档和组合安装有明确后果确认。未保存编辑切换需选择保留或放弃，目录刷新不把服务器值灌入本页编辑。写入忙／未知锁定原位置，beforeunload 提醒保留草稿。

资源定位参数 `resource` 严格 UUID、禁止重复／空值，只查实际加载目录，缺失不选择首个资源代替。原操作完整请求和键保存在本会话浏览器，失败后按钮只读核对同键 receipt；明确“按原凭证核对并完成”只重放同键／同完整 payload 的纯数据库原操作，先查回执，不能换键或发送模型。`not_written` 只接受服务器明确事务证明，不从错误文字推断。已保存操作后目录读取失败保留正向回执，不重复修改。

局部试验选择实际已保存诊断组合，查看冻结消息与模型后确认一次调用。原资源及要求超 30000 字符明确拒绝，不裁剪内容。运行／预览键未知只读核对；结果展示中文，候选不直接覆写书。资源切换不能把旧试验冒充新资源的效果；反馈仅匹配该原资源／版本的成功输出，作者主观反馈不能升级质量问题。

> 白话比喻：目录像抽屉，打开抽屉不会把桌上没写完的稿纸扔掉。对应系统：只读刷新更新目录，不覆盖编辑草稿；真正采用需要再次确认。

> 速记方法：目录只读，草稿保留，原键核对，明确采用。

本阶段仅编码和静态 review；浏览器、GET、模型、构建和测试未运行，等待主任务统一验证。
