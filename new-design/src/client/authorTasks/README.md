# 运行记录页面

顶部挂载 `AuthorTaskCenterPage({api, bookId?})`，`api` 必须只提供 `listAuthorTasks` / `getAuthorTask`。产品名称“运行记录”；推荐路由 `/new-design/operations/records`，API 路由 `/author-tasks` 和 `/author-tasks/:kind/:id`。

左侧筛选／选择记录，右侧检视详情与公共凭证。刷新、分页、选择只读；唯一工作流相关入口是打开真实来源页的链接，不包含重试、继续、恢复、取消、采用、归档按钮。明确说明导航后果，具体动作由来源页展示上下文和保存回执后执行。

接口失败显示未完成步骤与保留内容。未知记录通过来源页核对原凭证，不根据空查询推断未执行。租约过期状态只投影数据库真实时间，不更新原运行状态；旧输出存在时返回来源页审阅／恢复保存结果，没有输出时显示待核对。部分来源页不能准确选中版本时用 `source.exact=false`，不能假称自动恢复。

生产导演记录显示原冻结范围的候选进度、已保存原模型回复／待补回执数量与“有警告”中文标签。中心不显示正文或模型警告全文，只跳回精确 `director?run=原UUID` 查看同一范围与原章节请求；没有重试、继续、暂停、结束或恢复执行按钮。完成候选不代表完书，旧章候选不证明当前章调用成功，局部警告不在聚合页升级为全书阻断。

已明确结束的原过期调用仍可带“待核对”标签：结束释放占用，不代表模型未发送、结果成功或用量已知。原真实尝试和请求凭证保留，页面只导航到原范围／原章检视，不提供新的调用按钮。

沿用 `.nd-shell` 主题变量；平面列表、行分隔和选中标记代替嵌套卡片边框。控件有可访问标签、键盘焦点、文字状态及 `aria-busy`，不靠颜色区分失败；窄屏改为上下布局。异步列表与详情通过独立请求代次防止迟到结果覆盖选择，卸载后不更新。

所选详情实际挂载 `AuthorUsagePanel`，只调用原用量摘要 GET；原任务精确 task/book 范围，其他书内来源明确为本书汇总。已知用量、未知原尝试、未记账尝试和未知费用分开显示，不重试、记账或推测模型调用已验收。详见 `../authorUsage/README.md`。

> 白话比喻：航站楼屏幕可以查看登机状态，但改签要去对应柜台。对应到系统：记录页只查看状态，正式创作决定必须回来源页。

> 速记方法：看、筛、选、查、回来源；不在记录页办创作决定。

静态审阅及用例编码完成后交由主任务集中验证；本模块不自行启动服务、调用 GET 或运行构建／测试。UI 实际验收由用户完成。
