# 书架与正式阅读

功能对应仍有明确遗漏，见 [旧版书架功能对应审计](../../../../docs/wiki/product/new-design-bookshelf-parity-audit.md)。本模块不能宣称完整复刻旧版；来源链接不等于旧版同页弹层、执行或直接下载。

书架保留 `/new-design/books`，阅读页为 `/new-design/books/:bookId/reading?chapter=:chapterDocumentId`。原 `?view=workbench` 与默认入口现在落在同一作品列表，回收站仍由 `?view=trash` 打开；搜索、状态筛选、排序和 24 本分页不变。开书草稿用原 session 深链继续，与正式作品分开计数。

采用正文、稳定章节、未曾采用的候选和本次导演范围结果独立展示。正文进度只比较明确采用的正文与采用章节计划，不表示全书完稿。封面来自本书精确版本的有效 book mount；未绑定的候选图片不充当正式封面。封面维护和导出返回现有来源页，由用户在那里选择、检查并明确执行。

布局参考旧 NovelList / NovelShelfCard 的封面、书名和继续入口，但不再维护书架／工作台两套作品卡片。所有作品采用同一行式卡片：首屏只显示封面、状态、已采用正文进度和一个继续入口；每页最多三本正在推进的作品置顶且不在下方重复。八步入口、分类、候选事实、简易创作、AI 驾驶舱、封面、导出与回收站操作保留在逐书展开区；运行记录与后台状态再收一层，打开后才读取本书详细运行信息。高级筛选和其他开书方式也默认收起，原参数入口保留。开书草稿默认折叠，原草稿入口仍全部可展开访问。封面进入正式阅读，书名进入本书工作区；粗指针设备保留 44px 操作尺寸。

回收站只修改 books.status 与 revision，保留原 bookId、spaceId、安装快照、正文、资料和关联。恢复不启动 AI。原状态转移以 bookId、action、expectedRevision 构成完整比较并更新输入；仅对应目标状态和 expectedRevision+1 可以核对这次幂等转移。后续操作造成修订变化时保留未知结果，不用相似列表内容证明成功。浏览器完整输入在提交前保留，未知状态禁止第二次提交。

旧 `/novels` 实际挂载 NovelList，包含书架/工作台、搜索、草稿/已发布、原创/续写及长短篇筛选、更新/创建/进度排序、分页、封面管理、TXT 导出、删除与 simple 入口。本批按用户要求以可恢复回收站承接移除行为。新版没有相同的发布状态及长短篇正式字段，不能用任务完成或创建方法虚构这些筛选；已有续写/参考开书方式仍从原开书页面使用。simple 的正式阅读由新阅读页承接，导演执行/恢复留在原来源页。

UI 验收由用户完成，不自动运行浏览器或截图。专项验证使用源码及模拟事务；真实数据库仅执行只读事务，不为了测试归档真实作品或调用模型。
