# 完整资料到明确图片发送

公共角色试用和书内图片共用此面板。先只读读取完整资料，再编辑原草稿；明确优化一次后显示中英完整结果和缺失信息，再选择原文／中文／英文送回原图片表单，选择本身不调用图片模型。

完整本地帧保存范围、资料、原草稿、预分配原键和结果。坏帧、容量故障、整帧回读差异锁定写入；同一来源使用浏览器排他锁。未知请求先只读核对，已有回复仅明确续存。确认未写入证明加原键不存在核对后，才能明确释放这次准备，草稿和资料保留；未找到请求不能推断模型未调用。

未确认优化、存储故障或忙态向父页面传保护，阻止图片发送及离开。优化选择交回图片表单仍须显示并明确确认原图片请求。

客户端编译及选择合同单元通过；新增真实页面、跨页并发、刷新／响应丢失和实际优化 PG 尚无完整证据，不能据本地帧实现声明验收。
