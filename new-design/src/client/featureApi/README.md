# 新功能中央接口边界

世界检查、创作提炼、图片生成、人物对话、专业图形和导演总控台共享中央 `request` 传输与错误回执校验；本模块仅映射正式 HTTP 合同，不调用模型、不推断来源、不修改业务状态。人物对话接口接线随模块收口，不以注册任务代替页面或执行验证。

> 白话比喻：前台把业务转交对应窗口，不替窗口记账。对应到系统：接口映射保留原请求与精确来源，业务写入和恢复证明由各模块处理。

> 速记方法：传输共用，合同分开；未知查原单，不换单重发。

图片使用专属原生图像连接，不能走默认文字模型。创作提炼入口必须明确本书与专项模式。世界修复先正常保存资料，再显式登记质量修复，两个结果不可混为同一保存。

本批中央接线仅完成编码及静态检查，迁移、构建、测试、真实模型和界面验收均等待全部阶段编码完成后的统一验证。
