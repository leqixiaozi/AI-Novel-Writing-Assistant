# 公共树形目录

通过本目录 `index.ts` 门面消费 `TreeNavigation`。目录采用紧凑的左侧多层结构：独立展开箭头、逐层缩进、中文名称、可选计数／状态与选中标记。内容与编辑表单由来源页显示在右侧，不能由公共树组件猜测需要调用的业务接口。

> 白话比喻：公共目录像文件柜的抽屉标签，负责告诉你文件在哪里，不负责把文件改掉。对应系统：展开是本地显示状态，业务选择、写入和失败恢复仍由来源页负责。

> 速记方法：箭头展开，名称选择，来源页保存；名称没有选择处理器时只展开。

## 交互边界

- `nodes` 使用稳定业务 ID；`selectedIds` 由来源页控制。没有内部业务选择副本，来源页拒绝切换时不提前改变选中标记。
- 分支名称可以仅展开；明确的 `onSelect` 才通知来源页。可选 `onExpand` 用于来源页的懒加载，禁用时只能改变本地折叠状态，不能触发业务选择。选择处理器存在时避免重复触发同一懒加载选择。
- `href` 用于页面导航，标签渲染为原生链接而不是业务选择按钮；链接不调用 `onSelect` 或 `onExpand`。禁用时移除链接地址并阻止点击，正常导航继续交由浏览器和来源页既有离开保护处理。
- `leading` 可放单／多选输入，`actions` 可放来源页提供的排序／新建按钮。权限、排序范围、级联规则和选择上限属于来源页，不因显示统一而改变。
- 搜索保留匹配项的祖先，选中节点自动展开祖先。搜索／折叠不修改右侧草稿，不调用模型、不提交数据库命令。
- `flatNavigation` 从实际父 ID 构造显示树，可传入原模块排序规则。缺失父项或损坏环仅在显示上兜底展示，不重写持久父关系。
- 使用原生导航、列表、按钮与可选输入；Tab 可达、Enter 可用、焦点可见，不声明未实现方向键规则的 ARIA tree。
- 样式只使用既有语义主题变量，窄屏目录独立滚动，触控按钮至少 44px。没有引入字体、依赖或新的业务状态表。
