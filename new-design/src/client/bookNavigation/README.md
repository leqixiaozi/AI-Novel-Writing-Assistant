# 书籍工作区导航边界

## 分组与来源

进入书籍页面后，左侧直接显示功能树，右侧显示原页面内容。树的四个主分组为创作概览、故事设定、故事创作、完本与导出。本书设置位于书名旁。`navigation.ts` 保留全部原页面键及原路径；`BOOK_NAV_GROUPS` 只决定展示归属，不建立另一套业务页面。功能导航采用左树，不同时再渲染顶部模块 Tab 或下拉功能菜单。

> 白话比喻：书店把同一批书按主题放进不同书架，不重新印一批书。对应到系统：主菜单是分组，树叶链接仍指向原页面和原保存流程。

> 速记方法：分组只导航，保存回来源。折叠菜单不是业务提交、候选采用或错误恢复。

## 交互规则

- 功能树是常驻左栏，不是顶部按钮或弹出菜单。目录箭头只展开分支，不卸载编辑区，不修改 URL，不提交数据。
- 左栏右上角箭头向左收起菜单为 44px 窄栏，反向箭头展开。只隐藏树，不卸载树或右侧编辑器；折叠状态按本书 ID 保存为浏览器会话偏好，存储不可用时仍可使用内存状态。展开按钮始终可见并提供 `aria-controls`／`aria-expanded`。折叠不隐藏右侧错误或恢复入口。
- 只有一个目标页面的分组直接链接到原页面，避免为打开概览或规划制造多层展开操作。当前目标的祖先自动展开，当前页面高亮。
- 树目录复用 `tree` 模块的 `TreeNavigation`；叶子使用原生链接，支持浏览器新标签操作与页面既有离开保护。
- 树的当前项由页面传入的 `active` 决定，不因作者仅浏览另一分组就改变实际页面选中状态。
- 故事设定包括创作方向、世界与人物、资料及辅助工具；故事创作包括规划与正文、查看与分析、全书导演。本书设置不归入任一创作阶段；公共创作资源继续从公共资源入口进入，书籍树不混入公共资源的编辑入口，不会自动安装或覆盖本书资料。
- 主题颜色继承 `nd-shell` 的语义变量，不使用弹出层和阴影。桌面采用左右结构，收起后右侧自动释放宽度；小屏上下排列并保留收起按钮，不把编辑区挤成不可读窄列。
- 编排目录按右侧内容容器的实际宽度决定是否分列，不能仅凭整个屏幕宽度继续增加正文旁的栏目。

## 当前整合范围

全书编排的真实卷章场景目录复用共享树，按原 `parentObjectId`、`sortOrder` 展示并调用原选择及草稿保留逻辑。缺失来源仍显示原错误，不自动改选其他章节；断裂或循环父关系只做防死循环展示，不写回修复数据。

本阶段统一导航和编排目录；多维视图、专业图形、人物对话、视觉资产仍通过原页面承接，并未合并成同页五视图。创作方向入口 `/setting` 使用原本书创作表单，不另建存储。全书规划与章节规划尚未按编辑范围拆分。后续接入必须继续消费原业务正本及保存器，不复制正文、资料、版本或采用状态。

## 验证边界

本阶段仅静态 review。分组覆盖、原路径兼容及共享树接入的用例已编写，等待整批任务编码完成后的统一测试；未执行类型检查、测试、构建、浏览器检查或数据库迁移。
