# 知识与参考页面

入口 `/new-design/knowledge?bookId=<书籍 UUID>` 或 `/new-design/books/<UUID>/knowledge`；独立导航与本书导航均已挂载。API 由 `client/api.ts` 统一消费 `common/knowledgeReference` 合同，服务器入口在 `http/knowledgeReference`。

上传、解析、绑定、归档、引用采用共用原请求恢复控制。提交前先保存本机请求指针；不把全文或模型配置放入恢复标记。文件在提交前留在编辑器，未知结果时保留本机输入并锁定写入。只读查询未发现回执不能证明未提交；只有服务器明确确认未写入，才显示按原输入重试。回执须匹配本书、操作、原请求与准确资料；保存成功后刷新失败不撤销已确认回执。

正文分页须保持解析版本、哈希和连续偏移，不混入迟到的其他版本。引用从真实解析版本选择，使用已有上下文清单和允许资料类型的位置；不修改作者配方，不把绑定视为模型自动使用。语义检索缺失必须明确区分正文查找，不能伪造索引状态。

上传／解析／全文及原引用恢复已有本批隔离证据，双端编译通过；真实模型、作者环境及其余实际页面验收待验。页面默认资料／上传，索引与检索、设置分区；索引组件保持挂载，切换不丢原规格填写／问题／回执。未知索引在资料页显示提醒，仍可切到原恢复入口核对；语义命中查看精确原文时回资料页定位，不改引用语义。
