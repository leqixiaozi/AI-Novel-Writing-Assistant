# 章节正文与知识引用

正文只存入原章节档案的候选版本。页面复用正文编辑器及受控单章执行器；全书工作台嵌入同一页面，不另存正文，不自动采用或结算。

## 本章知识参考

作者显式读取本书已解析的真实参考候选，再逐项勾选最多 20 份。选择精确 `assetId / sourceVersionId / parsedVersionId / checksum`；普通界面展示中文标题及摘要，不要求输入键或 JSON。未解析参考不能选择，清单截断不能推断其余参考不存在。

白话比喻：写文章前选择要夹在桌面的几页参考资料，而不是把整间图书馆搬到桌上。对应代码：引用的是作者勾选的原文件及解析版本，不自动引用全书，不把参考当作小说正式事实。速记：先解析、明确选、冻结版、原单发。

本章选择随原正文草稿按本书、本章隔离保留；刷新候选不改变旧选择的解析版本。提交时来源与选区、正文基线冻结在同一个原请求里，服务器核对版本和校验凭证。来源过期或未返回时保留作者选择，作者可在本书知识中心核对或明确取消；不偷偷选择替代版本。

知识清单是只读 GET，不解析、不调用模型。跨章或跨书迟到读取不得更新候选、错误或忙状态。写入未知时保留原请求标识和知识选择，只核对原请求，不重新生成。人工稿件、知识选择、未知写凭证由同一保留动作处理，全书工作台离开也消费这一动作。

## 原质量问题的修复准备

质量页通过 `qualityIssue` 带回确切问题。准备修复只读重查问题版本、报告有效性和本章正文绑定；载入的是报告冻结的正文，不按当前另一候选代替。人工稿件、补充要求、未知请求或采用确认存在时不得覆盖，迟到读取同样遵循这个保护。问题描述及证据带入原章节修复要求，受现有输入上限约束，不能截断后假称完整。

准备不会调用模型、保存候选、接受修复或改变问题状态。作者仍需明确生成、比较、采用和结算；没有新复检报告时不自动标记已解决。

## 原回复审阅

原回复按本书、本章、原请求、冻结正文版本和修订正向核对，只读查看及明确复制。不自动覆盖手填，不自动保存或采用。本机文件回复凭证与数据库入库证明分开说明，前者不能用于自动续入；模型结果未知也不能据此重新生成。

本阶段只完成编码、静态审阅和用例编写，测试、构建、启动、数据库读取、模型调用与迁移尚未执行。
