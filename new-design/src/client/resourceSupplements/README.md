# 资源补充来源页

本模块嵌入既有的人物资源与章节结果确认页面，保持原布局及人工编辑／确认流程。稳定章创建独立清单，原冲突仅针对绑定字段创建独立修正；候选生成、人工确认、影响确认和正式保存由作者分别明确操作。

`StartPanel`持久完整独立创建命令；`CommitPanel`分别持久完整影响确认与正式保存命令，通过既有原请求保护核对完整回执。恢复只读、不换原输入、不自动重跑AI。父页面收到未知结果锁定回调后不得切换章节或继续写入，原核对按钮仍须可用。正式面板挂载位置必须独立于人工核对／稳定结果分支，确保真实提交后父刷新不会打断凭证收尾。

`IssueList`与`IssuePanel`读取明确人物／章节的实际冲突，失败保留错误，不当成无冲突。旧issue范围仅供重新读取实际来源；新预览再次核对完整人物、资源、关系、字段、正文与历史依据，不静默选择维度或用当前值解释历史。只读来源hook使用书籍／会话／正文身份及异步序列守卫，跨书或离页回复不得替换当前来源。

实际浏览器验证使用独立临时前后端及保留空库，唯一provider桩不涉及真实模型。生产作者库迁移与现有服务加载另行执行，不凭代码或HTTP200宣称在线可用。
