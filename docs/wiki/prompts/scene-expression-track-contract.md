# 场景表达轨道与提示词合同

场景表达轨道是全书编排中的可选写法元数据。系统固定提供场景节奏、句段节拍、细节展开、镜头距离和语言修饰度五条轨道；每条轨道只有 L1—L5 五档。作品不能新建其他维度，也不能改写五档的标准含义。

> 🏠 **白话比喻**：场景卡像已经写好的拍摄清单，表达轨道像剪辑台的五组旋钮。旋钮可以让镜头更近、节奏更快、细节更多，但不能凭空换演员、加证物或改结局。对应到系统里：表达点只保存写法，事件、人物、线索、因果和场景结果继续由原编排资料决定。
>
> 🧠 **速记方法**：场景定“写什么”，轨道定“怎么写”；保存只存点，生成才读点。

## 绑定与界面

一个表达点以 `(novelId, sceneId, dimensionKey)` 唯一定位。`sceneId` 必须属于本书现存的 `ChapterPlanScene`；场景换章或重排后，表达点仍跟随同一个稳定场景 ID。

轨道继续使用全书编排的章节列。每章只占一列，该章的 S1、S2 等场景点以多个小圆圈排在列内，不为每个场景另建整列。章节格只显示章号和场景数，悬停可查看章节名称；场景点悬停或获得焦点时显示章号、场景序号和完整标题。五个维度名称放在轨道标题右侧的竖排窄列中，不覆盖第一章点位。

圆圈同时表达设置状态和档位：未设置是淡色虚线圆；L1 空心、L2 四分之一填充、L3 半填充、L4 四分之三填充、L5 全填充。圆圈本身不显示“底座”、场景编号或档位文字，完整信息由悬浮提示提供。

- 左键点击只选择点位。
- 左键上下拖动吸附到 L1—L5；左右移动不会换绑场景。
- 方向键上、下可调整一档。
- 右键、菜单键或 `Shift+F10` 打开宽右侧详情。
- 恢复底座写法会删除该点；`unset` 与作者明确设置 L3 不相同。

轨道显示偏好复用全书编排草稿的 `pinnedTracks`。保存显示偏好时保留旧的章级表达键，因此旧合同和旧界面记录不会被五条新轨道覆盖。

## 数据与并发

`SceneExpressionPoint` 独立存储，不写入 `ChapterPlanScene`、`Chapter.sceneCards` 或 `Chapter.content`。书级开关 `Novel.sceneExpressionTracksEnabled` 默认关闭。客户端携带开关、整组点位和 `expectedRevision` 保存；服务端验证五种固定维度、L1—L5、重复绑定、跨作品场景与版本冲突，然后在串行化事务内校验所有权并增删改。开关和点位共享同一个版本，两个窗口不能分别覆盖对方。

接口：

- `GET /api/novels/:id/book-arrangement` 返回 `sceneExpressionEnabled`、`sceneExpressionPoints` 和 `sceneExpressionRevision`。
- `GET /api/novels/:id/book-arrangement/scene-expression-points` 单独读取 `enabled`、点位和版本。
- `PUT /api/novels/:id/book-arrangement/scene-expression-points` 使用幂等键和版本号保存 `enabled` 与点位。

刷新前的未保存点位与编排草稿一起进入当前作品的会话恢复记录。重新打开后由作者明确恢复；若另一窗口已经保存，新请求按旧版本号冲突，不覆盖新数据。

## 写作时如何生效

只有作者明确打开“用于后续写作”并保存后，`GenerationContextAssembler` 才查询当前章节真实场景的表达点。开关关闭时不查询新表、不生成新提示词，也不增加模型调用；点位仍保留，方便以后重新启用。有点位时，`novel.scene.expression_controls` 按场景标题编译标准片段：

```text
【场景 S2：摸供桌，撬夹层】
- 场景节奏：L4／紧凑推进。压缩重复说明和无作用停顿……
- 镜头距离：L5／沉浸贴身。持续贴近当前视角人物已有感知……
```

提示词总边界固定为“只改变表达，不改变故事”。作者备注也被解释为写法备注，不能借备注新增事实。无法同时满足表达档位和场景事实时，以事实、人物知情和已有因果为先。

保存表达点不会自动改写已经存在的正文。它只在后续正常章节生成或明确发起的候选重写中生效；正文仍走原候选、核对和采纳流程。

## 维护检查

修改轨道时至少验证：

1. 五种维度和五档字典没有漂移。
2. 同章多场景共用一个章节列，点位仍按场景顺序排列。
3. 书级开关默认关闭；关闭时不查询、不注入，明确启用后，未设置仍不注入，L3 会注入“均衡”要求。
4. 保存前后场景任务、事件、人物、线索、正文和模型调用数不变。
5. 旧版本或跨作品场景被拒绝，重复提交可恢复。
