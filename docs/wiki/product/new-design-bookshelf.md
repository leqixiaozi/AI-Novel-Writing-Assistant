# 新设计书架、阅读与回收站

## 背景与对应关系

旧版 `/novels` 挂载的 NovelList 提供默认书架及工作台两种视图、作品搜索、状态/创作形式筛选、排序、24 本分页、封面、继续创作、阅读、TXT 导出与移除。simple 深链以章节阅读和真实进展为主，导演执行命令仍会改变原任务。

新书架保留 `/new-design/books`，用本书已有卡片、规划、采用正文和正式任务事实构成读模型。创作操作返回项目设定、故事设定、故事规划、正文创作及精确原章节/导演来源；阅读目录只包含正式采用的非空未归档正文。图片维护和导出沿现有来源页执行，书架不自动调用 AI 或恢复导演。

## 当前规则

- 任务完成、候选生成、正文采用、章节稳定和全书完稿是独立事实。正文进度用采用章节计划作分母，不能以导演范围执行完成证明全书完成。
- 没有新版正式字段支撑的已发布、长短篇等筛选不能由创建方法或任务状态猜测。续写和参考开书仍沿现有开书方式使用；短篇整套业务须另行确定范围。
- 按用户明确选择，作品移除为归档至回收站；恢复原 bookId 与所有正文、卡片、安装快照及关联。普通书架、统计与正常 book 选择器已有 active 条件，归档后自然排除。
- 归档前核对正式任务来源及未被运行记录投影的原生占用；运行、暂停、待恢复和未知结果阻止归档。恢复不执行 AI，不实现永久删除或草稿删除。
- 归档和恢复以原状态及修订号作比较并更新，完整输入先留在浏览器。响应丢失后核对原转移，不能把其他修订或当前列表看作原请求证明。

## 部署边界与验证

本机单 API 进程的在途 HTTP 写请求与归档互斥，持久化任务检查用于拒绝已有后台工作。扩展多实例或独立调度器前须统一事务锁与任务领取 active 门禁。本批不执行数据库迁移、重置、真实归档测试或模型调用；通过模拟事务覆盖归档、重放、恢复、暂停占用和未知 COMMIT，实际数据库仅核对只读快照与来源。
