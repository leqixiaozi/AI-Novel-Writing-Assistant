# 新设计多维视图与质量闭环

## 决策

- 一本书只有一套正式资料、正文、事实和状态；多维页面只是不同阅读入口。
- 查看偏好可以独立保存，但不得保存人物、关系、事件、道具或质量结果副本。
- 客观连续性与主观审美建议分开呈现和筛选。
- AI 修订只产生正文候选，不能覆盖采用正文。
- AGE 和 pgvector 只加速读取，不能承载编辑结果。

> 🏠 **白话比喻**：它像医院里的病历、检验单和会诊看板。窗口不同，病历号和原始记录只有一份。对应到系统：所有入口回到 PostgreSQL 正本，视图不能另起一套真相。

> 🧠 **速记方法**：**看法可多，真相唯一；AI 开建议，作者做决定。**
