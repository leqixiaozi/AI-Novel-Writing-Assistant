# 人物与世界参考页面的版本安装

## 背景与决定

旧版固定字段和新版动态规格不应建立两套资料正本。参考页面恢复布局与入口后，缺字段需通过已发布内容规格和表单版本提供；不能为复刻旧 UI 把作者意图写成正式状态。

## 当前规则

- 人物性别、背景属于档案；成长方向、当前行动目标属于规划。起始处境草稿与正式初始状态分别记录。长期目标保留原稳定键。
- 所有新增默认字段可选，旧书明确预览后新增，不自动回填已有卡片。规划字段同时配置真实结算策略 none，防止继承人物默认 tracked。
- 公共规格发布、表单版本与冻结模板版本属于同一个原请求事务。现有书籍保留既有快照，逐书决定应用。
- 模板安全字段同步只登记实际安装的字段／字典／标签。关联表单、关系和源版本映射需要独立安装合同；模板版本号相同并不能证明全部构件等价。
- 保存使用完整原输入哈希与当次不可变回执。当前目录、重名内容、最新字段版本都不能证明原请求成功。旧回执不足时保持未知，不能重放原请求伪造成功。
- 只有尚未进入 COMMIT 且物理回滚得到确认，才能说本次未写入。提交响应中断后的回滚不证明提交失败。

## 维护与验证

预览应冻结书籍修订、规格版本和来源，并在应用前校验；未发布草稿不得覆盖。隔离测试使用全新空数据库与真实约束，保留测试库，不把用户业务表作为 fixture。用户库迁移、具体旧书安装和在线模型调用是独立验收动作。

相关模块：new-design/src/server/database/referenceParity、fieldExtensions、structureWrites、templateStore；storyWorkspace 拥有参考布局，专业投影仍只读。

## 关联规格的版本规则

公共关联表单与冻结模板属于一次发布，现有书不随发布修改。逐书安装建立精确来源映射，书内活跃选择固定真实私有版本；多个候选不能根据数组顺序猜测。关系尚无独立不可变版本表时，冻结模板版本加定义哈希才是来源，不能把可变关系 ID 声称为版本。书内关系按含义独立安装，使用时核对哈希。

新表单版本与既有实例分别管理。选择新版本用于新建；既有实例只有明确升级才追加挂载版本，原来源引用、局部扩展、填写和历史全部保留。局部字段的枚举选项拥有各挂载独立身份，字典范围映射到实际私有树和节点版本。写作关联的状态策略固定 disabled/none，关联道具不代表持有，关联地点不代表当前位置，使用范围不代表正文上下文约束。

原命令完整输入与当次结果持久到只追加回执。关联历史记录单独存在不足以证明原输入。客户端先保存完整命令与局部填写基线，再写入；已确认写入后的刷新失败仍保留待核对凭证。其他草稿基线不能跟随一次保存自动更新，采用最新来源也须核对用户实际看到的来源修订。迟到响应不得覆盖切换后的范围。

## 外显定义与候选保存

外显字段沿用实际已发布分组；已有样貌、语言习惯和标志动作保留，新可选体态、穿着、细节、声音和登场印象明确发布后逐书新增。缺失或不兼容样貌定义返回映射问题，不暗中改键／转换已有值。固定状态策略 none，外显草稿不形成状态或事实。

生成只冻结候选。采用按所选字段、原来源哈希和完整原键记录不可变草稿；单项编辑与批量确认均通过标准作者保存器形成真实版本与 AI 来源。批量原子事务在校验全部来源后保存所有项目和回执，任何项失败全体回滚。并发原键先锁后创建串行化快照，重复提交返回冻结原结果；丢失提交确认只能只读核对。线上加载与用户验收独立于隔离验证。

## 人物资源回填边界

资源账本需要用户明确选择真实已发布的持有关系及状态维度，普通创作关联不等于持有；未知基线不可由AI猜数。可编辑会话的确切采用正文可准备范围内候选，复用原章节审阅和结算，正式状态只随明确确认改变。完整原请求哈希区分人物版本、资源、关系和规格，读取原回执不能变更为当前最新章。独立资源资产需要未注册普通启动的085手动存储守卫；未安装或已回退时不发送模型。稳定会话补充需先核对下游影响，不能直接重开。见[资源账本模块边界](../../../new-design/src/server/database/characterResources/README.md)。
