# 创作概览与故事规划

创作概览帮助你判断一本书准备到哪里；故事规划让你按故事、卷、章节和场景逐层填写安排。页面使用树形目录和表单，不要求理解底层数据结构。

## 先看创作概览

打开一本书后，概览会显示故事方向、资料准备情况、卷章规划、已写章节、待确认内容、质量问题和最近任务。每一项都来自真实数据，并可进入对应页面继续处理；没有记录时会显示“暂无”。

## 完成前三章规划

建议按以下顺序准备：

1. 填写并采用故事总览。
2. 建立第一卷计划，确认它采用哪一版故事方向。
3. 为前三章分别填写目标、视角、故事时间、地点、参与者、必须发生、必须保留、禁止事项、伏笔安排和预期变化。
4. 比较候选并明确采用每章的一版计划。
5. 进入章节创作时，系统只读取采用的章节计划。

> 🏠 **白话比喻**：候选像导演准备的多套拍摄方案，采用相当于圈定本场要执行的一套。其他方案仍保留，但不会混进正式拍摄。

> 🧠 **速记方法**：**故事定方向，卷定阶段，章定任务，场景定动作；候选先比较，采用才执行。**

## 修改和回退

保存修改会新增候选，不会覆盖创作依据。你可以采用新候选，也可以重新采用某个历史版本。多人或多个页面同时编辑时，页面会提示服务器修订，并保留本地填写供核对。

规划中的预期变化不会直接改写人物、关系、道具、伏笔或正文。它们需要在后续创作与确认流程中形成正式记录。

## 数据同步

代码、SQL 和数据说明通过 Git 同步。你填写的规划与采用记录保存在 PostgreSQL 中；换机器开发时，还需要执行项目的数据库逻辑备份和恢复流程。
