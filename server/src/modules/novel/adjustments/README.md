# 可选人工调整边界

本模块将明确启用的作者要求、候选和交接接入原小说流程。未携带调整合同的请求保持旧业务含义。

候选与编辑版本不写 Chapter.content；正式采纳才调用原事实提交与同步。DirectorArtifact 记录来源依赖，NovelSideEffectJob 承担持久同步，没有第二个任务引擎或事实库。

人工接管在短事务中提升章写入许可 epoch。运行在开始时捕获 epoch，完成回调必须恢复同一上下文并在业务事务内校验；完成交接不能重新授权旧运行。模型调用不得包含在事务内。

> 白话比喻：旧送货单可留档，但地址变更后不能继续用旧单派送。速记：候选留档，采纳入账，旧单失效。

卷段人工调整由 `BookArrangementVolumeService` 编排，`ArrangementVolumeAdapter` 接入原卷文档与 `persistActiveVolumeWorkspace`。草稿字段 `volumeEdits` 可选，卷预览与后续写作要求候选分开；旧保存／生成合同不增加必填参数。预览只读取原资料并保存候选，不调用会自动激活或补全规划的入口。

正式应用在同一事务内完成版本核对、交接与同步校验、原卷版本保存、授权卷归属更新、旧写入许可失效、所选草稿消费和回执持久化。底座持久化函数的可选 `affectedVolumeIds` 仅供明确范围的新合同使用，默认调用仍处理完整原文档；未授权卷及其 Arc 兼容记录不得被局部调整重写。跨卷移动保留原章节规划 ID 与任务资料；移出且没有归入其他卷的链接保存在调整前卷版本，正文和实际章序不变。

影响预览列出原人物职责、关系、场景、事件和导演资料；结构检查不能代替剧情审核。修改卷的节拍表和关联重平衡建议需重新核对，不用全书人物重建或新增模型调用代替作者的范围授权。

> 白话比喻：换一间教室的课表，只改授权课程的安排，历史课表留档，教材不改。速记：限定卷、留原单、核冲突、一次生效。
